## 공개 전달 승인과 큰 ZIP 분리

2026-10-27 사용자는 저장소가 공개임을 안내받고 **「로고·영상을 공개 커밋·푸시하고, 큰 레이어 ZIP은 메인 PC로 별도 전달」**을 선택했다.

`title_brush_v4_layers.zip`은13,063,308바이트로 저장소의 일반 파일10MiB 제한을 넘어서 **git에는 넣지 않는다**. Release나 공개 링크에도 업로드하지 않는다. 메인 PC 별도 전달 목표 경로:

`C:\workspace\handoffs\joseon-title-v4-20261027\title_brush_v4_layers.zip`

ZIP에는 배경·조/선/헌/터/스·밑줄·도장·영문PNG 및 레이어/검증 자료가 있다. 해당 어두운 배경용 마스크이므로 임의 밝은 배경에 쓰는 범용 클린 알파로 보증하지 않는다.

## 검증 파일 구분

- `MANIFEST.json` — **원래 승인 패키지 전체**의 보존 기록. 별도 전달 ZIP도 포함하므로 GitHub 체크아웃만으로 전체 항목 검증은 불가능하다. 원본 기록을 임의 변경하지 않았다.
- `PUBLIC_MANIFEST.json` — **이번 git 공개 패키지** 파일의 SHA256/바이트. 이 파일 자체는 해시 목록에서 제외한다. 별도ZIP은 `separate_delivery`로 구분한다.
- `QA.json` — 제작 당시 검증 기록. 전달 전 원본 SHA 대조·ZIP CRC·두 영상 디코딩을 다시 검사한다.

제작 스크립트·이전 시안은 이번 커밋 대상이 아니다. 원본 보관처는 WSL의 `joseon-assets/inbox/gpt/2026-10-19/title_fusion_subtitle/`이며, 이번 패키지만으로 원래 렌더 프로그램까지 재현된다고 주장하지 않는다.
