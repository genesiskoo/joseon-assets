# 조선헌터스 SNS 오디오 자료 — 2026-10-10

모든 동봉 파일은 공개용으로 준비한 확정본입니다. 파일명과 대응표에 공개 가능 여부·스포일러 수준을 표시했습니다.

- NPC 음성: 새 확정 성우 전체 237편 중 공개용 196편. 스토리 보호가 필요한 41편은 이 공개 묶음에서 제외했습니다.
- 효과음: 베기·스킬·부적·빙결·치명타·드랍·줍기·UI WAV 44편.
- Suno BGM 원본: 승인된 던전 곡 5편과 판소리 오프닝 「못골에 깃든 것」 1편, 총 6편. 다운로드한 원본을 변환 없이 복사했습니다.
- 억쇠: 성우 배정은 확정됐으나 정적 대본 음성은 0편입니다.
- 현재 대본의 추가 18줄은 아직 음성이 없으므로 동봉되지 않았습니다.

`voice_lines.csv`는 파일명·캐릭터·대사를 대응합니다. `sfx_cues.csv`는 효과음의 용도를, `bgm_tracks.csv`는 곡명·사용 장면·원본 파일명·출처·원본 SHA256을 대응합니다. CSV는 한국어가 Excel에서 바로 보이도록 UTF-8 BOM으로 저장했습니다.

대응표의 `spoiler=none`은 일반 공개용, `spoiler=minor-quest`는 초반 의뢰 진행·보고 내용입니다. 판소리 오프닝의 `spoiler=opening-premise`는 게임 시작에 소개되는 마을과 도사의 설정을 담았다는 뜻입니다. SNS에 초반 의뢰의 결과도 감추려면 `minor-quest` 파일을 제외하세요. 보호한 41편의 대사와 파일명은 공개 자료에 싣지 않았습니다.

오디오 바이너리는 이 자료와 연결된 Release 오디오 묶음에 들어 있습니다. 표의 `audio/...` 경로는 오디오 묶음 안의 파일을 가리킵니다. 루트 안내에 적힌 압축 해제 위치를 따르세요.

음성은 게임에 적용된 확정 ElevenLabs v4 버전입니다. 효과음은 현재 게임에 적용된 WAV를 그대로 복사했습니다. Suno 원본은 던전 일반 층·필드에서 사용하는 승인곡 다섯 편과 게임 오프닝에서 사용하는 판소리 한 편입니다. 다른 마을·긴장 전투·보스 음악을 Suno 곡으로 표시하지 않았습니다.
