# UI 에셋 반입 보완 — #76

기존 #63 스킨 4종과 #64 아이템 아이콘 17종을 유지하고 미연결된 가방 40칸·장비 7칸·벨트·스킬 슬롯을 공통 UiSkin에 연결한다. 점유 아이템의 바탕은 가장자리 8px를 남기고 반투명하게 그려 목재 테두리를 가리지 않는다. 드롭 가능/불가, 선택·잠금·쿨다운 표시와 클릭 영역은 유지한다.

추가 제작은 32px 커서와 9슬라이스 제목띠 SVG 2종이다. 흑색 외곽·무광 놋쇠·남색 면의 단순 도형으로 기존 스킨과 맞추며 커서 핫스폿은 (3,2). 제목띠는 창 제목 뒤에만 표시하고 클릭 가능한 탭 기능은 추가하지 않는다. 소스는 joseon-assets/workbench/ui/completion_76에 보관하고 게임 assets/sprites/ui/skin에 반입한다.

왜 이 구조인가: 현행 즉시 모드 UI와 이미 연결된 17종 아이콘을 활용하면 입력·레이아웃 변경 없이 누락된 아트를 적용할 수 있다. 전체 Theme 전환이나 완성된 아이콘 재생성은 이번 등록 작업에 필요하지 않아 제외한다. 검수는 17종 데이터 연결 검사와 ui_windows 실제 렌더 10장, 별도 아이템 대조표로 한다.

- SVG 2종 반입·Godot import 완료. 기존 UI 4종·아이콘 17종 재사용(이번 작업에서 재생성하지 않음).
- `ITEMS_TEST fails=0 PASS`, `E2E ui_windows PASS (검사 28)`, 창 캡처 10장 생성. 가방·상점 캡처 직접 확인.
- 검수 이미지: `docs/art/ui_76/{inventory,vendor,items_catalog}.png`.
- 초기 제한 실행은 사용자 폴더 저장 권한 오류가 있어 정상 권한으로 다시 실행. 최종 검수 로그에는 ERROR 없음.
- 이번 범위에 스킬 아이콘 신규 제작, 스크롤바, 탭 전환 기능은 포함하지 않음.
