# #108 H1 검술 아이콘 3종 후보

2026-09-21 · [제작 #108](https://github.com/genesiskoo/joseon-hunters/issues/108) · [HUD 반입 #109](https://github.com/genesiskoo/joseon-hunters/issues/109)

상태: **제작·파일 검수 완료 / PD 채택 대기**. UI 표시가 없는 128×128 투명 PNG 3종이다. 게임의 `data/skills/` id와 파일명을 맞췄으며 실제 HUD/스킬창에는 아직 적용하지 않았다.

| 파일 | 동작·구분 단서 |
|---|---|
| `slash.png` | 참격 — 크게 열린 대각 반달 궤적 |
| `dash_strike.png` | 돌진베기 — 오른쪽을 향한 수평 쐐기, 뒤쪽의 갈라진 먹 꼬리 |
| `whirl.png` | 회오리베기 — 큰 중앙 구멍이 남는 한 바퀴 회전 |

먼저 [크기·상태 검수판](review/skills_preview.png)과 [흑백·실루엣 진단](review/monochrome_diagnostic.png)을 본다. 30/60px는 아이콘 내용 영역의 크기이고 바깥 8px 여백이 추가되어 모의 슬롯은 46/76px다. 확대 보기가 아닌 해당 이미지 안에서 실제 픽셀 크기로 배치했다. 그림의 밝기·재질과 형태를 보려면 128px 두 바탕 비교를 사용한다.

## 제작·검증 기록

- 내장 imagegen으로 3종 제작 + 돌진 두께 보강 1회 = 총 4회. 모델 버전은 도구가 노출하지 않는다.
- 참격의 스타일 참조는 #102의 H1 환도. 돌진·회오리는 생성한 참격의 먹선/무광 명암을 이어받았다. 원본을 기계적으로 변형해 새 아이콘을 만들지 않았다.
- 요청 1024px, 실제 원본 모두 1254×1254 RGBA. 실제 투명 알파 0과 불투명 알파 255 확인. 납품 3종 모두 128×128 RGBA, 그림 경계 `[12,12,116,116]` 안. 회오리 중심 알파는 0.
- 첫 돌진은 그림 경계 높이 29px로 30px 모의 UI에서 약했다. 추가 생성 후 같은 128px 납품의 경계 높이 44px로 보강했다. 가로 길이는 103px로 동일하다. 첫 원본·프롬프트·첫 검수판은 `rejected/`에 보존했다.
- 검수판에서 기본/선택/잠금/쿨다운 50% 상태와 흑백·단색 실루엣을 육안 확인했다. 반달·쐐기·중앙 빈 원 형태가 남고, 잠금 기호가 핵심 형태를 가리지 않는다. 참격은 쿨다운 반쪽 덮개에서 밝은 부분이 많이 가려지므로 실제 HUD 대비는 #109에서 다시 확인한다.
- 정확한 프롬프트·참조 해시·원본 경로·파일 SHA256·알파 통계는 `sources/*.json`과 `manifest.json`에 있다.

포장은 #102와 동일한 알파 지지 영역(8/255 이상)에 2px 여유를 둔 사각 크롭, 비율 보존 리사이즈, 중앙 배치만 한다. 크롭 안 RGBA를 재칠하거나 배경 키잉하지 않는다. 흑백/단색은 검수판 전용 진단이며 납품 이미지는 변환하지 않는다.

**검수판은 UI 모의 합성이다.** 선택선·잠금·반원 쿨다운 덮개를 Python으로 그린 것이며 Godot의 현재 HUD 렌더나 입력 테스트 결과가 아니다. 이미지에 글자/단축키/테두리/덮개를 굽지 않았으므로 #109가 상태를 독립적으로 표시할 수 있다. 슬롯 배경·숫자·등급색·장착/해제·쿨다운 타이밍·실제 표시 해상도 검수는 #109 범위다. 기각 폴더는 납품에 포함하지 않는다.

재현: `python workbench/ui/skills_h1_108/package_skills.py` (Pillow 필요). 같은 저장소의 `../icons_readability_102/package_review.py`에서 알파 포장·축소 함수를 공유하며 그 해시를 매니페스트에 기록한다. UI 상태 그림은 이 폴더에서만 합성한다.

왜 이 구조인가: 작은 액션바에서 색보다 동작의 방향·열린 공간으로 먼저 구분하도록 세 궤적의 외형을 다르게 했다. 상세 검무 장면과 발광 테두리는 작은 크기에서 정보를 늘리고 H1 무광 톤을 깨므로 사용하지 않았다. 스킬 그림과 UI 상태를 분리하면 동일 에셋을 스킬창과 HUD에서 일관되게 사용한다.
