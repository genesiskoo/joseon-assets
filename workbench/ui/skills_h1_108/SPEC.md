# #108 H1 검술 아이콘 3종

2026-09-21 · 참격(slash), 돌진베기(dash_strike), 회오리베기(whirl). 게임 자료 data/skills의 id를 그대로 쓴다. PD가 Codex 담당 제작을 진행하도록 지시했으며 #102는 PD 검수로 인계했다.

내장 imagegen, 개별 3회부터 시작. H1 기존 아이콘의 먹 윤곽·넓은 무광 명암과 먹선 VFX 언어를 이어받는다. 얼굴/복장/장면 없이 동작을 요약한 큰 검 궤적을 구성한다. 참격=대각선 굵은 단일 반달 궤적, 돌진=오른쪽으로 뻗는 수평 쐐기와 짧은 뒤꼬리, 회오리=중앙이 크게 빈 한 바퀴 회전. 밝은 회백/철회색 면에 먹 윤곽, 빛번짐/네온/색상만으로 구별 금지. 재질 참조만 사용하고 원본 검 자체를 단순 재사용하지 않는다.

1024px 정사각 투명 원본을 요청하고 실제 크기를 기록한다. 128px RGBA 납품, 그림 영역 104px 안, 12px 여유. 이미지 안에 글자/숫자/단축키/액자 없음. 알파 지지 사각 크롭·비율 보존 리사이즈·중앙 배치 외 그림 수정은 imagegen을 쓴다.

검수: 30/60px 실제 크기의 기본/선택/잠금/쿨다운 50% 덮개 모의 UI, 흑백 휘도 및 실루엣 진단에서 세 동작을 구분한다. 덮개는 에셋이 아니라 UI 검수용이며 실제 HUD #109 구현과 구별한다. 정확한 프롬프트/출처/해시/크롭/검증 기록과 후보·기각본은 모두 보존하고 대화에 표시한다. 채택 전 공식 HUD 파일은 변경하지 않는다.

왜 이 구조인가: 텍스트 없이 동작의 방향과 궤적을 가장 큰 단서로 만들면 작은 액션바에서도 인지하고 잠금/쿨다운 상태를 UI가 독립적으로 표현할 수 있다. 캐릭터 전신이나 세밀한 검무 장면은 축소 시 뭉개지므로 제외한다.

검수 변경: 돌진 첫 후보는 30px 잠금/쿨다운에서 면적이 부족해 원본 궤적 두께를 imagegen으로 보강. 최종 128px 그림 경계 높이 29→44px(폭103px 유지), 기각 원본/프롬프트/검수판 보존. 나머지 두 아이콘은 최초 후보 유지.
