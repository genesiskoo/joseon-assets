# #102 H1 아이콘 축소 식별성 보강

2026-09-21 PD가 codex 담당 제작을 진행하도록 지시. 기존 H1 무광 먹선 아이콘을 개별 편집하며 17종 전체를 다시 만들지 않는다. 원본 정체성/범주/색 계열을 유지하고 작은 크기의 큰 명암·윤곽을 보강한다.

대상 8종: leather_shoes, leather_armor, jade_charm, long_sword, iron_sword, hwando, ident_scroll, town_portal. 도구 = 기본 내장 imagegen, 각 아이콘별 1회 편집부터 시작(1024px 정사각/실제 알파 요구); 필요시 문제 하나만 추가 교정. 특정 모델 버전은 도구가 노출하지 않는 한 기록하지 않는다.

가죽신/가죽갑은 넓은 중간톤으로 발등·옷깃·가슴을 나누되 밝은 외곽선/발광/과도한 미세 질감은 만들지 않는다. 옥패는 큰 회녹색 원반과 짧은 고리. 검은 직선 넓은 장검/단순 짧은 철검/분명한 곡선 환도의 실루엣 차이를 남긴다. 부적은 펼친 직사각과 접힌 모서리/매듭 등 큰 차이를 주며 붉은 인장과 먹문양 정체성을 유지한다.

납품은 비율 보존 128px RGBA, 알파 트림·리사이즈·중앙 배치만 기계 처리한다. 이미지의 밝기/색/형태/배경 제거는 Python으로 수정하지 않는다. 원본과 정확한 프롬프트·참조·SHA256·알파 경계·작은 크기 시트를 함께 보관한다.

#101 실제 슬롯은 다른 게임 세션 담당으로 미완료. 저채도 중성 슬롯 검수판은 '제안 바탕/실게임 아님'으로 명시한다. 현재 목재 슬롯과 제안 바탕을 나란히 비교하며 원본32px/작은24px·46px 및 실제 다칸 표시를 확인한다. 최종 게임 반입·입력 검수는 PD 채택 후 #103. 다른 세션의 #98 코드·기존 공식 PNG/데이터는 수정하지 않는다.

왜 이 구조인가: 슬롯 개선과 그림 개선의 효과를 분리해 과도한 전체 밝기 상향 없이 문제가 남은 아이콘만 수정한다. 개별 원본으로 생성하면 1장짜리 아틀라스의 칸 침범·누락을 피하고 각 형태를 검수할 수 있다.

검수 변경: 철검·환도 첫 대각선 후보는 1×3칸 가로폭에 묶여 작게 보였다. 같은 디자인을 세로 구도로 재생성해 납품 후보로 교체하고 첫 원본/프롬프트/검수판은 rejected/에 보존한다. 이미지 자체의 색 보정이나 비율 왜곡은 하지 않는다. 작은 정사각 표시의 검 구분은 반입 #103에서 별도 확인한다.
