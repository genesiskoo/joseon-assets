## 검증과 한계

내장 imagegen으로 8종을 개별 편집하고 철검·환도 2종을 추가 수정했다(총 10회). 모델 버전은 도구가 노출하지 않는다. 요청은 1024px 정사각, 실제 결과는 모두 **1254×1254 RGBA**였다. 원본에 실제 0/255 알파가 있으며 8종 납품 파일은 **128×128 RGBA**, 그림 경계는 `[12,12,116,116]` 안이다. 정확한 프롬프트·참조·원본 위치·SHA256·알파 통계는 `sources/*.json` 및 `manifest.json`에 기록했다.

후처리는 알파 8/255 이상 지지 영역에 2px 여유를 둔 **사각 크롭**, 비율 보존 리사이즈, 중앙 배치뿐이다. 원본의 거의 투명한 외곽 점이 그림 크기를 줄이지 않도록 크롭 범위만 산정하며, 크롭 안 RGBA를 재칠하거나 배경색을 키잉하지 않는다. 원본 전체는 그대로 보존한다.

비교판은 `UiSkin.item_icon`의 알파 경계→8px 여백→비율 보존 배치와 8px 9슬라이스를 Pillow로 재현한 **CPU 검수판**이다. Godot 스크린샷이나 런타임 테스트 결과가 아니다. 색 공간·픽셀 반올림·필터 차이는 남을 수 있다. 중성 바탕은 **제안 바탕 / 실게임 아님**이며 #101 최종 구현과 다를 수 있다. 기존 슬롯은 `review/baseline/slot.png`, 기존 아이콘은 같은 폴더에 스냅샷으로 보관했다. 선택·등급색·드래그·상점 입력 검수는 #103 범위다.

눈으로 확인한 판정: 가죽류는 큰 면과 윤곽이 개선되지만 굵은 목조 내부 격자의 시각적 간섭은 남는다. 옥패·부적의 축소 식별 개선은 분명하다. 검 3종은 1×3칸을 사용하도록 구도를 통일했다. 무명도포·짚신은 변경 없이 밝은 장비 기준점으로만 비교판에 넣었다.

재현: `python workbench/ui/icons_readability_102/package_review.py` (Pillow 필요). 기존 검수 입력을 사용한다. `--capture-inputs --game <게임 repo>`는 현재 게임 기준 스냅샷을 갱신하므로 의도적으로 기준을 바꿀 때만 쓴다.

왜 이 구조인가: H1 정체성을 유지하면서 문제가 있는 아이템만 보강하고, 같은 조건의 전후 비교로 그림 변경과 슬롯 변경의 효과를 분리한다. 다칸에서 확인된 대각선 축소 문제는 소스 구도를 바꾸어 해결해 게임에 임시 확대 로직을 넣지 않는다. 공식 파일 교체는 PD 채택 후 #103에서 한 번에 수행한다.
