# Workbench

검토 중인 작업물과 테스트 결과를 보관한다. 게임 또는 공식 에셋으로 승인된 상태가 아니다.

## 구조

- `candidates/`: 채택 여부를 검토 중인 생성 후보
- `probes/`: 화풍·구도·맵 등 비교 실험
- `smoke-tests/`: API와 생성 파이프라인 연결 검증 결과
- `tests/`: 스프라이트·Aseprite 등 제작 테스트

## 규칙

1. provider와 작업일을 경로 또는 메타데이터에 기록한다.
2. 가능하면 prompt, seed, 모델, 비용을 JSON 또는 Markdown으로 함께 보관한다.
3. 승인 전에는 공식 에셋을 덮어쓰지 않는다.
4. 승인 시 결과를 목적 폴더로 복사하고 source 경로를 정리 로그에 기록한다.
5. 폐기 시 바로 삭제하지 말고 필요한 경우 `archive/`로 이동한다.
