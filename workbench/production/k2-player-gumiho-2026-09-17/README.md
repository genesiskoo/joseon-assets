# K2 PC·구미호 확장과 도호 복장 보강

PD 지시 순서: K2 스타일로 PC·구미호 확장 → 주인공이 NPC처럼 평범함 → 기존 복장 디자인 차용 + 생성 후 검증.

## 최신 비교본

**도호는 [R2](K2_D_R2_costume_restore.png)가 최신 후보다.** 기존 D03의 겹소매·분할 도포·원형 소매 문양·하단 학/소나무 문양·푸른 원형 패·갓끈을 차용했다. K2의 무광 명암과 한국적인 인물 표현을 유지하는 방향이다. 기존 D03 승인 이미지나 게임 자산을 덮어쓰지 않았다.

| 코드 | 이미지 | 검토 내용 |
|---|---|---|
| A-D / A-G / A-C | [PC 3인](K2_A_player_trio.png) | 도호·귀새·청연을 K2로 통일. 이후 도호 존재감 부족 지적을 받아 H/R로 보강 |
| A-F1 / A-F3 | [구미호 변신 전후](K2_A_gumiho_forms.png) | 같은 성인 얼굴·흑발·금안·붉은 한복. F1 꼬리 없음·단검, F3 꼬리 끝 1+4+4 육안 확인 |
| H1 / H2 / H3 | [도호 실루엣 3안](K2_H_doho_hero_options.png) | 능청 검객 / 퇴마 도사 / 유랑 협객 탐색. 개별 채택 전 |
| R1 | [D03 복장 복원 1차](K2_D_R1_costume_restore.png) | 원본 복식과 주연성은 회복. 초상 갓 크롭·얼굴 광택을 R2에서 보정 |
| R2 | [D03 복장 + K2 표현 보정](K2_D_R2_costume_restore.png) | 최신 원화 후보. 아래 재검수 완료 |

처음 제안한 별도 B 세트는 PD의 연속 피드백에 따라 H1/H2/H3와 D03 복장 복원으로 방향을 바꿨다. 별도 B 구미호 이미지는 생성하지 않았다. A 구미호를 최신 도호와 같은 세트로 확정한 것도 아니다.

## 독립 시각 검수

`narrative-world /root/npc_variants_brief`가 K2·D03·R1을 직접 열어 비교하고 R2를 재검수했다. 부모 에이전트도 생성 결과를 직접 확인했다.

| 항목 | R1 | R2 |
|---|---|---|
| D03 복장 차용 | PASS: 겹도포·문양·푸른 패·적색 띠·흑립·어깨 위 검 | 유지 |
| 주인공 위계 | PASS: 비대칭 겹옷·장식 집중으로 강화 | 유지. 같은 크기 NPC와 인게임 비교는 미실시 |
| 한국적인 인상 | PASS: 흑립·동정·도포·매듭이 먼저 읽힘 | 유지 |
| K2 얼굴/명암 | 주의: 확대 얼굴의 광택과 머리 묘사는 D03에 가까움 | 개선: 코/입술 광택 감소·머리 명암 단순화. K2보다 미형 표현이 강한 차이는 남음 |
| 프레이밍 | 전신/검 온전, 초상 흑립 상단 크롭 | PASS: 초상 갓 전체·상단/좌우 여백 확보 |
| 손·검·몸 | 명확한 연결·사지 오류 미관찰 | 새로운 명확한 오류 미관찰 |

이는 **원화 대조 검수**다. 실제 3D·리깅·인게임 검증은 아니며, 작은 게임 화면에서 잔자수·구슬이 뭉치는지는 후속 모델 제작 때 확인해야 한다. 인게임은 남색 겹옷·붉은 띠·큰 푸른 패·검을 우선하고 잔장식을 줄인다.

## 제작 기록

내장 image_gen 5회, 원본 5장 보존. 실제 모델 ID 미노출. 코드·런타임·GLB 수정 없음. 새 원화 및 H안·R2 채택 확정 전. [실제 호출 프롬프트](PROMPTS.md) · [참조/크기/해시/QA manifest](manifest.json) · [생성 기록](generations.csv)

같은 그림체 안에서도 주인공은 복식의 큰 형태와 소품·명암 중심으로 NPC보다 뚜렷하게 구분한다. 기존 복장 시그니처를 재사용해 정체성을 이어가고, 장식 추가만으로 차별화하면 작은 게임 화면에서 뭉치므로 형태와 집중 위치를 함께 검수한다.
