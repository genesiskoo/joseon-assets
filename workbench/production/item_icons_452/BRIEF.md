## 3. 생산과 검수

내장 image_gen 물체별 독립 호출, 진짜 투명 배경. 승인 D1 원화2장을 화풍 참조로 사용하고 원본/프롬프트/생성경로/해시를 보존한다. 현재 공유 UiSkin·궁서 제목을 읽는 외부 Godot 검수판으로 변경 전 글리프와 후보 PNG를 같은 배치에서 비교한다. 40px/검정슬롯/30·48·60px와 확대 원화를 직접 검수한다. 후보는 짧은 검수 프로세스 메모리에만 올리며 실제 가방·상점 반입은 채택 뒤 별도 카드다. JPG1280폭/각300KB 이하/총6장 이하, 원본PNG/raw는 joseon-assets reports/452에 보존한다. 전체 현재 정의·기존 승인 그림 해시를 비교해 보존을 검증한다.

## 4. 왜 이 구조인가

물체마다 독립 원화를 만들고 현재 점유 크기에 결정적으로 패킹하면 종이·광물·이빨·털·철의 실루엣을 작은 가방 칸에서도 구별할 수 있다. 새 슬롯 액자나 글자를 이미지에 합치는 대안은 기존 UiSkin 테두리/수량 표시와 겹치고 교체를 어렵게 하므로 기각한다. 서로 닮기 쉬운 두 흰 털은 넓이·길이·냉온색을 함께 구별한다. 게임 데이터 변경 없이 실제 렌더를 검수해 채택 전에도 비교 가능한 후보로 보존한다.
