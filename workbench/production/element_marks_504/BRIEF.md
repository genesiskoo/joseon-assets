# #504 속성 표식5 원화 계약

D-081의 한 글자 한자 제외와 elements_v2의 먹 붓5종을 따른다. 불꽃 세 혀·한기 육각·벼락 두 꺾임·살 큰 구멍 소용돌이·영기 둥근 혼불을 진짜 투명 배경의 흰 먹 원본으로 제작해 기존 속성색/저항 회색을 유지할 수 있도록 한다. 검정 RGB를 곱셈 틴트해 어두워지는 오류를 피한다. 원본1024, 표시12/14/16/18px에서 모양으로 구별하고 밝은 흙바닥/어두운 UI에서 함께 검수한다.

생성은 Comfy Cloud GPT Image2.5 flare medium1024 정사각, 참조0·각1장 총5장, 현 badge 추정$0.094+입력문장 비용. 초소형 단순 실루엣의 불필요한 잔무늬를 줄인다. 최초출력과 alpha/원문/요청·작업ID/SHA를 보존한다. 결과에 대한 무기록 재제출·충전·구독 변경·push 없음.

현재 caller는 피해 Label3D(font23), HUD glyph17, 캐릭터 glyph21, 문자열 툴팁15이다. 원화 채택 뒤 texture 계약과 실제 caller를 교체하며 승패·피해 숫자·색·약점1.5배/0.15초·상태 의미를 유지한다. 이 단계는 원화 준비이고 PNG만으로 게임 한자가 교체됐다고 보고하지 않는다. 최종 반입은 원화 PD 채택 뒤 전/후 같은 구도3쌍과 관련 검사를 포함한다.
