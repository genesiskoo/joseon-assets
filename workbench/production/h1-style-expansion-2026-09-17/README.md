이번 인물 시험의 Meshy 사용량은 80 credits. 적 원화4장을 Meshy에 전송해 각각1개를 생성하는 단계는 자동 승인 심사가 명시 승인 부족으로 거절했다. 사용자 답변 전에는 전송하지 않는다.

최종 반입 전에는 손끝/도포 조형, 상인 외형·키·폴리곤 예산, 3D 텍스처 해상도(인물·계단2K, 아틀라스1254²), 게임의 충돌·경로·가림·동작을 보완해야 한다. 원화 검수와 실제 모델의 최종 합격은 별도다. 공식 반입은 채택 파일을 지목한 뒤 프로젝트 D-064 절차를 따른다.

이미지는 built-in image_gen으로 생성·수정했고 실제 모델 ID는 도구에서 노출되지 않는다. 생성 PNG의 로컬 리터칭은 하지 않았다. 갤러리/초상은 CSS·SVG 표시 영역을 사용하며, 재질은 원본 PNG의 UV 좌표로 적용했다. 배포 응답 기록에서는 만료되는 다운로드 서명만 제거했으며 작업 ID·상태·실행 오류는 보존했다.
