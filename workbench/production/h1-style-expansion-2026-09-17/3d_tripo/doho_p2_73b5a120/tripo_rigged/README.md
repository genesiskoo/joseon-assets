# Tripo / Mixamo 비교 진행 기록

2026-09-17. PD 지시: 같은 도호 모델을 Tripo 내부 리깅·애니메이션과 Mixamo로 비교.

- Tripo 텍스처 생성 완료: 20크레딧. 휴머노이드 v1.0 리깅 완료: 추가20크레딧. 잔액3,050.
- 웹에서 걷기·달리기·베기 재생 확인. 프리셋 선택은 생성/로딩 후 다시 선택해야 재생되는 현상이 있었다.
- 다운로드 원본은 PD가 직접 받은 FBX ZIP. 실측 1K=1024², 2K=2048², 4K=4096². 모두 메시1, 정점5672, 삼각형10594, 본41. 애니메이션0개.
- 웹 재생과 파일 확보를 구분: 현재 ZIP에는 애니메이션이 없다. 게임 반입 준비 완료로 간주하지 않는다.
- Mixamo: 동일 무텍스처 geometry FBX 업로드·정면 확인·관절마커 배치·리깅 요청까지 수행. 이후 마커 화면으로 돌아왔으며 성공 결과 미확인. 텍스처 포함 정적 FBX도 준비됨.
- 현재 비교 판정 미완료. Mixamo 완료본·동일 동작·고정 카메라 검수가 필요하다. Chrome 제어 연결이 끊겨 웹 작업 대기.
- 다운로드 차단은 PD의 직접 다운로드로 파일 확보 해결. 영구적인 브라우저 설정 변경은 수행하지 않았다.

리깅 결과를 별도 보존해 동일 입력에서 두 서비스의 관절·도포·소매 변형을 비교한다. 기존 게임 모델 교체는 하지 않았다.
