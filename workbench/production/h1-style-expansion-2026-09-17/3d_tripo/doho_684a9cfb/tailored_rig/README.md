# 새 도호 체형 전용 리그 1차 (#55 후속)

사용자는 새 외형을 유지하고 리그·동작을 새 체형에 맞추도록 승인했다. 기존 리그 전이본은 비교 기준으로 남긴다. 새 외형의 Mixamo 관절 위치를 기준으로 관절 정렬을 검토하고 넓은 소매·도포·허리끈의 보조본 및 웨이트를 구성한다. 기존 걷기·달리기는 동작 원본으로 사용하되 새 rest 공간으로 옮기고 자세·발 접지를 보정한다. 새 모델의 메시와 PBR은 보존한다.

1차 수용 기준: 무가중 정점0, 키1.7, 유효한 walk/run 클립, 반복 경계·발 접지 실측 및 여러 위상 렌더, Godot 실행. 정량 개선과 시각 개선을 구분하고 자동 검사 통과만으로 최종 품질을 승인하지 않는다. 테스트씬 tools/doho_tailored_rig_test.tscn에서 전이본/체형전용 후보를 함께 비교한다. 본게임 모델은 유지한다.

검수 주의: 매 프레임 양발 중 최저점을 지면에 강제로 맞추면 달리기의 공중 구간이 사라질 수 있다. 공중 구간과 접지 오차를 구분하며, 수평 발 미끄러짐은 별도 planted-foot 검증이 필요하다. 반복 경계는 본 회전과 위치 끝점을 함께 확인한다. 새 리그의 검 소켓은 별도 튜닝 전이므로 후보에서 무기를 숨긴다.

## 1차 결과 (2026-09-18)

새 외형의 Mixamo25 관절에 소매·도포·허리끈 보조본 5개를 더한 30본, 11,999삼각형, 키1.70m. 메시·UV·PBR을 유지하고 기존 9클립을 새 rest 공간으로 리타겟했다. 새로 수작업 제작한 9동작이라는 뜻은 아니다. 보조본은 부모 관절을 따르며 천 물리는 없다. 기존 26본에 외형을 전이하는 방식은 새 체형과 옷의 변형 제어가 부족하여 비교 기준으로만 남겼다.

걷기·달리기 마지막15%를 시작 포즈로 연결했다. 걷기 발바닥 최저점 오차는 약 -0.39~+0.68cm, 달리기는 높이를 일정하게 -12.94cm 이동하여 공중 구간(최저 발바닥 최대8.35cm)을 보존했다. 이는 수평 미끄러짐 개선을 증명하지 않는다. walk_speed1.45/run_speed2.4는 기존 비교용 값으로 새 실측 속도가 아니다.

Godot model_check PASS, MODELS_TEST fails=0 PASS, 비교 씬 로드 및 화면 캡처 확인. 최종 품질 승인 전: 뒤로 젖힌 걷기 인상, 도포의 흰 패치·각진 접힘, 접지 중 수평 미끄러짐, 무기 소켓, 전투 클립 자세를 추가 검수해야 한다. cast는 이번 9클립에 포함되지 않는다. 본게임 도호는 교체하지 않았다.
