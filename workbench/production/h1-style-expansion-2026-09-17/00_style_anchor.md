# H1 공통 스타일 기준표

2026-09-17 · 도호 외형 D-071 · 공통 화풍 D-072 · 어두운 게임 톤 D-070

**기준 원본: [승인 보드 왼쪽 H1](references/H1_approved_board.png).** [확대 기준표](00_style_anchor.html)는 원본 PNG를 CSS 표시 영역으로만 확대한다. H2·H3·R1·R2는 포함하지 않으며 원본을 재생성·리터칭하지 않는다.

## 공통 묘사 규칙

| 요소 | 제작 기준 |
|---|---|
| 선·얼굴 | H1의 가는 윤곽선과 절제한 눈코입, 큰 얼굴 명암면을 공유한다. 도호의 여유 있는 눈매와 능청을 유지한다. NPC는 얼굴형·체형·백발·수염·표정으로 연령을 구분한다. |
| 겹옷·주름 | 어깨·팔꿈치·허리의 주요 주름과 벌어진 옷자락으로 큰 실루엣을 읽힌다. 동정·소매·매듭·자락의 연결을 보존하고 문양은 큰 면보다 약하게 둔다. |
| 재질 | 천·목재·석재를 무광의 큰 면으로 그리되 결·이음새만 각 재질에 맞게 구분한다. 검의 얇은 하이라이트와 작은 장식만 제한적으로 반짝인다. |
| 색 관계 | 도호는 큰 남색·먹색 면 → 얼굴 주변의 흰 동정 → 붉은 끈 → 작은 푸른 패의 관계를 따른다. HTML 색칸은 관계 설명용이며 새 HEX나 면적 비율 락이 아니다. |
| PC 위계 | 독자적인 실루엣·무기·얼굴 주변 대비·대표 소품으로 먼저 읽힌다. 다른 PC에게 도호의 얼굴·남색 복장·붉은 끈을 복제하지 않는다. |
| NPC 위계 | 직업 소품·체형·얼굴형·표정으로 구분한다. 주름 수나 사진 질감으로 별도 화풍이 되지 않게 한다. |
| 배경·소품 | 인물보다 대비와 잔디테일을 낮추고 이동면·출입구·상호작용 지점을 읽힌다. 기와·목재·석재·종이에 같은 선과 명암 방식을 적용한다. |
| 적·보스 | 같은 화풍 안에서 위협 방향·공격 실루엣·종별 소품을 구분한다. 구미호는 전후 형태의 얼굴 연속성을 지킨다. |

## 조명의 목적

- **제작 시트:** 밝고 중립적인 조명으로 얼굴·고유색·손·소품을 검사한다. 정측후면은 같은 축척으로 맞추고 리깅 입력은 빈손 중립 자세, 검은 별도 소품으로 제작한다. 장면 그림자·국소광·림라이트를 기본 텍스처에 굽지 않는다.
- **통합 장면:** D-070의 낮은 환경광과 제한된 국소광을 유지한다. 현재 실행 카메라의 실제 표시 크기에서 얼굴·손·검·이동면이 읽혀야 한다. 낮은 채도에서도 표정과 생활감을 남긴다.

## 인물별 보존점

| 인물 | 유지할 정체성 |
|---|---|
| 도호 H1 | 무수염의 능청 얼굴·흑립·남색 겹도포·벌어진 자락과 바지·흰 동정·붉은 끈·푸른 패·검. 목도리 없음. 어깨 위 검은 연출 포즈이며 리깅 자세와 구분한다. |
| 귀새 G02 | 각시탈·포니테일·흑홍 분할복·보라 내의·곡단검·홍사·여분 탈. 기동형 실루엣. |
| 청연 C01 | 상아색/옅은 청록의 긴 한복·넓은 소매·부채·방울·옥패. 차분한 인상. |
| NPC B1/B2/B3 | 상인: 넉넉한 체형·장부 / 무당: 가는 얼굴·능청·방울과 부채 / 촌장: 각진 얼굴·백수염·지팡이. |
| 구미호 F01/F03 | 같은 성인 얼굴·흑발·금안·붉은 한복. F01 인간형 → F03 황금빛 아홉 꼬리. 새 중간 형태를 추가하지 않는다. |

## 참조와 검수

참조 역할은 **H1 = 화풍 / 각 승인 캐릭터 = 정체성 / 현재 게임 = 크기·재질·조명·가독성 제약**이다. GT1 기반 게임 도호, 임시 캡슐·체커 바닥·렌더 오류는 H1의 외형을 덮어쓰는 참조로 쓰지 않는다.

원본의 얼굴·전신 대조 → PC·NPC·배경 나란히 비교 → 실제 표시 크기로 축소 확인 → 손·검·사지·의상 연결·프레이밍 확인 → 결함 보정 후 재검수한다. 원화 검수와 실제 3D·인게임 검증은 각각 기록한다.

**H1은 세 열 보드의 왼쪽 인물이다.** H2·H3·R1·R2를 혼합하지 않는다. R2/D03의 촘촘한 자수를 H1에 자동 추가하지 않는다.

HTML 원본 표시 영역(1536×1024 PNG 기준): 전신 `x=24, y=64, w=486, h=918`; 얼굴 `x=195, y=122, w=138, h=153`; 도포 `x=76, y=245, w=395, h=500`. 모두 왼쪽 H1 범위이며 이미지 파일 자체는 편집하지 않는다.
