# #128 못골 광장 H1 기준 화면 — 제작 사양

2026-09-21 / 제작 담당 codex / 게임 반입 담당 #151 claude.

사용자 지시: 전체 화면 개선 진단 → 티켓화 → 다음 작업 진행. 목표는 마을 전체를 다시 그리기 전에 PC·NPC·건축·소품이 한 화풍으로 읽히는 광장 한 화면을 시각 기준으로 만드는 것이다.

## 범위와 선행 상태

- H1(D-072)의 선·큰 형태·무광 명암, D-070의 실제 게임 톤, 승인 인물 정체성을 유지한다.
- 현재 게임 기준은 0aba611. #124 NPC 발광 제거, #135 도호/NPC 대기, #136 검·칼집, #137 도포 얼룩 수정이 반영된 버전이다. #125의 이전 NPC 흰 발광을 미술 기준으로 복제하지 않는다.
- 최신 게임을 별도 작업 트리에서 읽기 전용 촬영한다. 실제 화면과 생성 목표 시안은 파일명·문서·비교표에서 구분한다.
- #119 인물 색 정합은 아직 열려 있다. 생성 시안으로 인물 색 보정 완료를 선언하지 않는다. 실제 색 수치와 광원/재질 값의 확정은 #119/#151에서 수행한다.
- 신규 그림은 미채택 후보이며 실제 게임 자산·장면을 교체하지 않는다. 채택 후보 파일을 지목받은 뒤 #151로 인계한다.

## 제작물

1. 최신 광장의 실제 1280×720 화면과 같은 카메라에서 UI만 숨긴 원본.
2. A: 현행 동선/배치/스케일을 유지한 H1 무광 재질·큰 색면 기준. 건조한 흙마당, 먹빛 목재, 청회 기와, 누른 한지와 작은 등불.
3. B: A와 동일한 구도·물체·디자인에서 주변 명도/국소광만 조절한 어두운 비교안. 새로운 스타일·인물 디자인을 추가하지 않는다.
4. 원본/후보 비교표, 프롬프트·참조 해시·직접 QA, 채택 후 게임 적용 명세.

생성 도구는 내장 image_gen이며 모델 식별자가 노출되지 않으면 특정 모델 버전을 단정하지 않는다. 요청 출력은 각 1536×864(16:9) 1장, 실제 반환 해상도는 manifest에 따로 기록한다. 프로젝트 그림 편집은 image_gen으로만 한다. 비교표는 이미지 자체를 수정하지 않는 축소 배치다.

## 이미지별 참조 역할

- 최신 UI 없는 게임 캡처: 편집 대상. 카메라·화면 크기·PC/NPC 위치/스케일·랜드마크 배치 기준.
- `14_motgol_modules_props.png`: 목재·기와·한지의 형태/무광 묘사 참조. 시트 속 소품 상대 크기나 조명 밝기를 복사하지 않는다.
- `K2_H_doho_hero_options.png`: 왼쪽 H1만 공통 선/큰 명암 및 도호 정체성 참조. H2/H3는 사용하지 않는다. 실제 최신 모델의 어깨검·칼집·편한 대기 실루엣을 유지한다.
- B의 편집 대상은 A이며, 변경 변수는 광원/명암뿐이다.

## 검수 기준

- 도호는 흑립·남색 겹도포·붉은 끈·푸른 패·검·목도리 없음. 신규 인물, 동료 PC, 무수한 장신구를 추가하지 않는다.
- NPC3의 위치·역할·연령·고유 복식을 유지한다. NPC를 도호 얼굴/복식으로 통일하지 않는다.
- 캐릭터를 확대해서 돋보이게 하지 않는다. 넓은 색면과 바닥 대비로 인물과 발 위치를 읽히게 한다.
- 우물·서낭단·좌판·집·못·등불·주요 길의 상대 배치가 실제 캡처와 맞아야 한다. 랜드마크를 옮긴 결과는 레이아웃 제안이지 정확한 비교안으로 판정하지 않는다.
- 흙/목재/돌/천은 무광. 반짝임·검은 윤곽 반복·미세 돌알갱이·지붕 선의 밀도를 억제한다. 약한 반사는 실제 금속·물에만 제한한다.
- 도호/적/NPC 발밑과 클릭 이동면은 밝기가 낮아도 구별되어야 한다. 새 건물·소품이 이동면을 막으면 기각 또는 수정한다.
- 원화 검수 통과와 Godot의 성능·충돌·입력 검수는 분리한다. 이번 제작에서 게임 통합 통과를 주장하지 않는다.

## 왜 이 단위인가

광장에는 주인공·NPC·건축·소품·바닥·등불이 함께 있어 공통 재질과 명암을 한 번에 비교할 수 있다. 구역별로 개별 원화를 먼저 완성하면 서로 다른 디테일 밀도가 반복될 수 있어, 같은 카메라의 기준 화면과 조명 비교안을 먼저 만든다. 이 시안에서 채택된 규칙을 #129 한옥 및 #130/#131 외곽/입구에 적용하고, 게임 반입은 #151의 실제 검증으로 마무리한다.
