# #591 조합 아이콘 원화 — Codex 내장 생성

2026-10-03 PD의 직접 생성 지시로 Comfy 충전 대기를 해제했다. 실제 호출은 imagegen 스킬의 내장 image_gen이며, 도구가 정확한 백엔드 버전을 공개하지 않아 image2.5라는 모델 버전을 검증했다고 주장하지 않는다. Comfy·Higgsfield·외부 API 호출은 없다.

정본 combination_v2 §2.2·§4.4·§8 K9와 K10의 확정 이름에 따라 글자 부적8·비결서쪽1·조합유니크2를 각각 생성한다. 디아2R식 소지품 실물 재질, 한국 한지와 붉은 비문자 획, H1 무광 형태를 사용한다. 상위 단은 종이 품질·붉은 획 대비·절제된 마감으로 가치를 드러내고 한자로 구분하지 않는다. 감투·매듭은 재료와 실루엣을 구분한다.

개별 사각 원화(1024 요청, 실제 출력 크기 별도 기록)·진짜 투명 알파를 보존하고 40/80px·짙은 갈색/회색/밝은 바탕에서 검수한다. 선택·채택 전에는 게임 공식 에셋이나 정의를 바꾸지 않는다. 조합 유니크의 게임 반입은 #484의 공통 유니크 그림 해석 경로 뒤에 연결하며 베이스 그림을 덮어쓰지 않는다. 새 모델링·스탯·홈 수·값·드랍·세이브 변경은 없다.

왜 이 구조인가: 아트 원본과 실제 정의의 해시를 함께 기록하면 색·형태를 검수하면서 게임 수치를 지킬 수 있다. 물체 자체의 큰 형태로 구분해 작은 셀에서도 읽히게 하며, 글자를 넣어 종류를 구분하는 방법은 D-081에 어긋나 배제한다. 각 자산을 따로 생성해 한 장짜리 카탈로그를 잘라 쓰는 방법의 크기·알파 불일치를 피한다.

후보 상태: 미채택 · 게임 반입 전. 모든 프롬프트는 PLAN.json, 결과 및 해시는 생성 후 manifest.json에 남긴다. 원화와 리뷰 JPG는 공개 자산 기록 대상이며 비밀·검증 대량 원문은 포함하지 않는다.
