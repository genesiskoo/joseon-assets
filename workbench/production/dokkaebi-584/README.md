# #584 도깨비 NPC 원본

PD 미승인·게임 미반입 2D 후보 및 실패 이력. `raw/`는 생성 원본을 바이트 그대로 보존하고 `prompts/`와 `generation_requests.json`은 실제 요청을 기록한다. 외형 선택과 반입 규격 수용을 구분한다.
