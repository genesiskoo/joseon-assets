# #87 공통 목조 UI 부품 — 제작 계약

PD가 채택한 #393 A 채색 화풍과 D2b 소지품 판의 **검은 무광 목재·작은 놋쇠 장석**을 공통 창틀에 옮긴다. 기존 `panel.png`의 밝은 한지 중심·적갈 조각 장식은 흰 본문과 소지품 실루엣을 밀어냈다. 목표는 디아2R 참조 수치(`docs/design/d2r_ui_reference_2026-09-21.md`)의 창 중간 채도 ≤0.15·명도 ≤0.20, 강한 색 면적 ≤5%다. 한국식 반닫이 직선 짜맞춤을 쓰고 서양식 곡선 금장은 쓰지 않는다.

이번 카드 소관은 공통 **창판·버튼·현판·구슬 테두리**의 재질, 9슬라이스/알파 안전영역, 실제 창 검수다. 궁서 폰트 자체는 #104, 아이템 칸/아이콘은 #101·#393, HUD 배치는 #109, 툴팁 패널은 #155가 맡는다. 제목과 버튼 글자는 이미지에 굽지 않고 Godot에서 그린다. 소지품 격자는 검은 면으로 두고 다칸 물체 그림을 액자 안에 가두지 않는다.

## 생성 원본과 기술 반입

Built-in `image_gen`으로 각 부품을 **개별** 생성했다. `panel_source_v1.png`는 빈 직사각 창판, `button_source_v1.png`는 글자 없는 버튼, `orb_source_v1.png`는 가운데·바깥이 투명한 원형 테다. 참조 역할: #393 D2b = 채택 화풍·재질, 기존 `assets/sprites/ui/skin/panel.png` = 정면 비율만, 기존 `orb.png` = 원형 비율만. 원본은 이 폴더, 게임 사용본은 `prepared/`와 `joseon/assets/sprites/ui/skin/`에 둔다.

생성 원본을 그대로 9슬라이스로 쓰지 않는다. `prepare_skin.py`는 알파 바깥 여백을 자르고 원본 비율을 보존하는 게임 텍스처 크기(창판 400×216, 버튼 240×50, 구슬 144×144)로 **기하학적 리샘플만** 한다. 장식의 새 창작·합성·그림 수정은 하지 않는다. 고정 모서리와 반복되는 레일을 픽셀로 재고 네 방향 margin, content padding, 보이는 알파/실제 클릭 사각형을 `manifest.json`에 기록한다. 글자·숫자 없는 원본을 유지한다.

게임에서는 `UiSkin`의 StyleBoxTexture 방향별 margin과 `PANEL_TINT`를 새 원본의 어두운 중심에 맞게 갱신한다. 현판은 기존 SVG를 코드-native 형상 그대로 재질색만 바꾸며, 제목은 가운데 그린다. 구슬 그림은 채움 위에 덮는 테이므로 투명한 원 안에서 적/청이 살아야 한다.

검수: 변경 전/후 같은 `ui_windows` 창 10종, 소지품·캐릭터·기술·상점의 텍스트/테두리 충돌 0, 버튼 가시경계와 클릭 Rect 일치, 1280×720·1920×1080·2560×1440에서 구슬·현판·본문 읽힘. 원본/후보 모두 카드 사진에 남긴다. 실제 화면에서 강한 색 면적과 중앙 채도·명도를 다시 측정한다.
