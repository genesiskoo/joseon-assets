# #467 D1 1칸 장신구 5종 원화 계약

상위 #274의 핵심 잔여51 중 실제 ItemDef가 있는 복주머니 `pouch`(T1 호신부), 명두 `myeongdu`(T2 호신부), 야광주 `yagwangju`(T3 호신부), 옥가락지 `jade_ring`(T1 가락지), 금가락지 `gold_ring`(T2 가락지)의 독립 아이콘을 제작한다. 이름·소재는 `docs/design/item_catalog_v2.md §1.4`, 점유·단계·장착칸은 각 `data/items/<id>.tres`가 정본이다. 모두 1×1칸, 게임용 파일은 80×80 RGBA.

기존 #393 D1 소지품처럼 조선 다크 판타지의 실물 재질과 절제된 채색, 검정 가방칸에서 읽히는 외곽선을 쓴다. 한 장에 한 물체만, 정면에 가까운 약한 3/4 시점, 진짜 알파 투명 배경, 사방 원화 여백 ≥8%. UI 틀·글자·인물·보조 장비·화려한 외부 광채를 넣지 않는다. 원화의 알파16 기준 물체만 잘라 여백8%를 두고 Lanczos로 80×80에 비율 보존 패킹한다. 복주머니는 매듭·천, 명두는 손잡이 없는 놋쇠 무구 거울, 야광주는 구슬 자체의 은은한 빛과 패물 구조, 두 가락지는 옥/금 재질을 외부 등급 테두리 없이 구별한다.

원본·프롬프트·해시·게임용 후보·실제 UiSkin 40px/30px/48px/60px 검수판을 이 작업 트리에 둔다. 현재 게임의 아이템 정의·수치·드랍 모델·기존 PNG42장을 바꾸지 않는다. PD 시안 판정 뒤 별도 게임 반입 카드에서 연결한다. 따라서 이 후보 완료만으로는 #274 승인 잔여51을 차감하지 않는다.

왜 이 구조인가: 물체별 정본 소재와 1칸 점유를 고정하고 공통 UiSkin의 실제 축소 결과까지 보아야 다섯 이름이 장식·테두리 도움 없이 구분된다. 기존 H1 자리표시를 덮어쓰면 다른 장신구까지 같이 바뀌므로 기각한다.
