# #393 — A 채색 원화 스킬·D1 독립 물체 아이콘

PD 확정(2026-09-24): UI 틀과 스킬은 A 채색 원화, 소지품은 D1의 디아블로2R식 독립 물체. 이 폴더는 **개별 PNG 납품 후보**이며 아직 joseon 게임 저장소로 반입하지 않았다.

- `source/items/`: built-in image_gen 원본 11종. 실제 알파가 있는 물체 컷아웃.
- `source/skills/`: built-in image_gen 원본 6종. 행동 삽화.
- `game/items/`: 투명 배경 11종. 논리 40px 칸의 점유 크기를 2배 해상도로 저장하며 UI에서는 지정 footprint 크기로 축소한다. 액자·칸 배경은 포함하지 않는다.
- `game/skills/`: 불투명 128×128px 정사각 6종. UI의 스킬 칸에서 30/48/60px로 축소한다.
- `manifest.json`: 원본과 가공본 크기·SHA-256·아이템 알파 범위.
- `prepare_assets.py`: 원본을 바꾸지 않는 결정적 패킹/QA 시트 생성기. Pillow 필요. `python prepare_assets.py`.
- `project.godot`, `qa_godot.tscn`, `qa_godot.gd`: 별도 Godot 4.7 QA 미니 프로젝트. `godot --headless --import` 후 `godot -- --kind=skills`, `godot -- --kind=items`.
- `qa/godot_*_30_48_60.png`: **실제 Godot CanvasItem 렌더러** 결과. `qa/items_40px.png`와 `qa/skills_24_30_48_60px.png`는 Pillow 빠른 미리보기.

## 사용 전 확인

각 아이템은 `manifest.json`의 footprint와 함께 써야 한다. 옛 정사각 액자형 A/B/C2 소지품은 후보에서 철회했으며, 여기에는 포함하지 않았다. 한국식 환도·도포·가죽신·패랭이·도사 도구가 D1의 소재/실루엣을 따른다. 화염부의 火 문양을 단일 물체 소스와 Godot 검수에서 확인했다.

## QA 결과

- 11/11 물체의 투명 알파와 점유 크기, 6/6 스킬의 불투명 정사각 패킹 통과.
- Godot 4.7.2 Compatibility 렌더러에서 30/48/60px 스킬 6종·소지품 11종 출력 성공. 40px 실제 가방 칸 크기도 Pillow 미리보기로 확인.
- 가죽신은 어두운 칸 위에서 발등·굽이 구분되며, 환도는 1×3 세로 여백, 도포는 2×3 치마 폭을 유지한다.
- 작은 30px 스킬에서는 검술의 손/얼굴 세부가 사라진다. 참격은 대각 밝은 획, 돌진베기는 수평 방향, 회오리베기는 원형 획이 남아 구별된다. 도력방패는 인물보다 둘러싼 방어 호를 우선 읽어야 한다.
- 실제 게임 장비창/HUD에 배치한 캡처는 다음 **반입 카드**의 검수 범위다. 특히 기존 40px 배낭·9개 장비칸의 점유/겹침과 선택/비활성 상태를 그때 판정한다.

## 구조 선택

원본 17장은 재작업 가능하게 남기고, 그림과 셀 배경은 분리했다. 소지품을 UI 그리드의 칸 수로 패킹하면 긴 환도와 넓은 도포를 같은 파일/비율로 가방·장비칸·드래그에 재사용할 수 있다. 동일 정사각 프레임에 각 물건을 억지로 넣는 방식은 실제 점유 정보와 실루엣을 잃어 채택하지 않았다.
