# #393 — UI / 스킬·아이템 아이콘 리디자인 시안

상태: A·B·C2 생성·검수 완료, PD 방향 선택 대기. C1 초안도 보존, 모두 미채택. GitHub https://github.com/genesiskoo/joseon-hunters/issues/393

사용자 요청: UI와 아이콘을 새로 만든다. 아이콘은 스킬과 아이템 모두 포함한다. 게임 반입보다 화풍 선택을 위한 비교가 이번 범위다.

같은 12종을 A 채색 원화 / B 먹판 삽화 / C 음각 공예로 비교한다. 스킬은 참격·돌진베기·회오리베기·화염부·빙결부·도력방패, 아이템은 환도·남색도포·가죽신·탕약·도력병·옥패. 각 판에 HUD·소지품·술법 적용 예시를 함께 둔다. 실제 구현 캡처가 아닌 AI 생성 목표 시안이다.

H1 왼쪽 인물은 도호 정체성과 무광 큰 명암 기준. #245 캡처는 실제 게임의 어두운 톤 기준이며 기존 장식·단순 표식을 복제하지 않는다. 공통 문제는 동작 없는 스킬 표식, 어두운 신발의 낮은 대비, 서양식 포션/부츠, 아이콘보다 두꺼운 테두리다.

제작: built-in image_gen. 초기 방향 3장 + C의 재질 구분 보완 1장, 총 4장 생성. 1536×1024 목표. 실제 치수는 산출 후 manifest에 적는다. 이미지 안에는 궁서 느낌 제목, 명료한 본문과 숫자. 한국적 사물 실루엣·얇은 목조 UI·무광 재질·절제된 색을 공유한다. 검술에 속성 불꽃을 넣지 않고 불·얼음은 종이 부적에만 붙인다.

검수: 12종 내용/중복·분류, 도호 H1 식별, 가죽신·두 병 실루엣과 바탕 대비, 아이콘 안전 여백·한글, 8개 F키, 화면 및 확대 도안 직접 확인. 생성 시안의 축소 가독성은 시안 수준이며 30/48/60px 실제 Godot 검수는 화풍 채택 후 개별 PNG 제작 때 한다.

왜 이 구조인가: 같은 표본과 배치를 고정하고 표현 매체만 바꾸어 선택을 돕는다. 기존 표식에 테두리·질감만 더하는 방식은 스킬의 동작과 한국적 사물 식별을 해결하지 못하므로 제안하지 않는다.

프롬프트: prompt_A.txt / prompt_B.txt / prompt_C.txt / prompt_C2.txt. 참조 경로는 references.json. 원본 생성 이미지는 results/에 복사해 보존하고 기존 게임 에셋을 덮어쓰지 않는다.
