# #448 제작 사양 — D1 소지품 2차

#446/#393 채택 D1 독립물체·A 무광 손채색 화풍을 확장한다. 현재 ItemDef의 정자관·첨주·윤도·부적 목판(각2×2), 청심환·벽력부(각1×1)만 제작한다. 바탕은 실제 투명 알파, 프레임·글자·광원 효과·추가 물건은 금지. 원본 그대로 보존하며 alpha16 경계·8%여백·LANCZOS 패킹으로 각 점유×80px를 산출한다. 넓은 형태와 재질 명암으로 40px/칸에서 읽히게 한다.

정본은 equipment_slots_v2 §3.2·§4.2, item_catalog_v2 §6.1, elements_v2 §5.1. 겹관·뾰족한 쇠투구·풍수 나침반·부적 인쇄 나무판·환약·뇌법 부적이라는 명칭/물건은 확정 데이터이며, 아래 재료/세부 형태는 제작 해석으로 구분한다.

- 정자관: 겹관은 정본. 짙은 흑갈색 말총 같은 반투명 짜임과 얇은 테두리는 제작 해석.
- 첨주: 뾰족한 쇠투구는 정본. 간결한 세로 철판 이음·얇은 머리띠와 짧은 목덮개는 제작 해석.
- 윤도: 풍수 나침반·패철은 정본. 휴대 원반형 나무·황동, 동심 눈금·중앙 바늘은 제작 해석. 박물관의 종이 방위도를 목재 유물로 주장하지 않음.
- 부적 목판: 부적 찍는 나무판은 정본. 사각 인쇄판·얕은 새김·주사색 잔흔과 손잡이 없는 형태는 제작 해석.
- 청심환: 한방 환약은 정본. 작은 지름의 둥근 환·부분적으로 벌어진 한지 포장은 제작 해석.
- 벽력부: 뇌법·오뢰 부적은 정본. 접히지 않은 한지 한 장·먹선과 탁한 보랏빛 벼락 무늬는 제작 해석; 읽을 문자를 생성하지 않음.

참조: 국립민속박물관 한복 소개 https://www.nfm.go.kr/k-box/ui/hanbok/male.do (정자관 형상), 국립중앙박물관 방위도 https://www.museum.go.kr/site/main/relic/search/view?relicId=2708 (방위 체계/윤도 원리; 이 등록 유물의 재질은 종이). 시대 고증을 강제하지 않는 가공 조선 세계에 맞춘 제작 해석이다.

내장 image_gen으로 항목별 1회 생성. 현재 공통 UiSkin·ItemDef를 읽는 외부 Godot 검수판에서 기존/후보40px, 검정바탕,30/48/60px,승인 D1 기준표본을 비교한다. 후보 PNG는 검수 프로세스 메모리에만 넣는다. 실제 가방/상점/장비 반입은 채택 뒤 별도 카드다. 원본·프롬프트·파일 해시·알파·점유·raw 로그를 기록한다. 자료사진은 JPG1280폭·300KB이하·6장 이하, 원본과 스윕은 reports/448.

## 왜 이 구조인가

현재 아이템 점유와 공유 UiSkin을 기준으로 그림을 독립 물체로 제작하면 긴 물건과 작은 소모품의 실제 비율을 가방·장비·상점에서 유지할 수 있다. 정사각 장식 액자에 통일하는 대안은 점유·실루엣을 흐려 기각했다. 원본은 그대로 보존하고 패킹만 결정적으로 수행해 승인 뒤 반입과 교체를 재현한다.
