# #131 봉밀굴 잠긴 문턱 — 재사용 조립 후보

## 목적과 범위

현행 못골 북쪽 문턱은 1m 계단과 독립 석문 사이에 빈 땅이 남아 세트가 분리되어 보인다. 승인된 #336 `town_seal_gate`의 검푸른 바위 틈·부서진 돌틀·금줄·봉인문을 게임 아이소 시점에서 하나의 실루엣으로 읽히게 한다. #336 문 원화는 지평선이 보이는 3/4 구도라 **색·밀도·물체 관계**만 참조하고 배치 각도는 게임 카메라로 판정한다. D-077에 따라 이 문은 잠겨 있고 **세 수하의 봉인 조각**을 안내한다. 실제 입장 동선은 못골→들녘→흑랑 굴이다.

이 묶음은 **시각 모델 후보**다. 클릭면·길찾기·충돌·봉인 메시지·조명·배치는 게임 환경 담당 #344가 기존 `DungeonEntrance` 계약을 유지하며 처리한다. 문 앞 걷는 중심 2u에는 큰 잔해를 두지 않는다. 문턱 조명은 따뜻한 길등에서 차가운 균열 한 점으로 넘어가되, 발과 클릭면을 가리지 않아야 한다.

## 제작 선택

새 유료 3D 생성 없이 이미 게임에 반입된 `cave_arch`(유기적 바위 외곽), `seal_door`(검푸른 석문)를 스크립트로 한 GLB에 조립한다. 이유는 기존 두 모델의 재질 밀도가 #321 주변 바위와 이미 맞고, #336 원화의 요구가 새 생물형 모양보다 **조립 경계·세 조각 홈·파손 흔적**에 있기 때문이다. `seal_door`의 원형 표식은 유지하되 전면에 세 홈을 명확히 추가한다. 기존 `stairs_down`도 검토했지만 목재 판자처럼 보이고 0.61u 높이가 평면 클릭면과 어긋나므로, 후보에서는 얕은 닳은 돌 계단을 직접 만든다. 게임의 원본 계단 인스턴스와 동시에 보이지 않게 한다.

대안인 독립 소품 재배치는 현재의 틈·재질 단절을 반복하고, 새 Meshy 생성은 승인 모델과 비슷한 모양을 다시 얻는 데 비용이 든다. 후보가 카메라에서 충분히 읽히지 않으면 그때 문짝만 새로 발주한다.

## 모델 계약

- Blender 기준 X 가로·Y 깊이·Z 높이. 앞면은 −Y, 발판 윗면은 Z≈0. Godot GLB로 내보내면 +Y 높이, 문 앞은 +Z.
- 아치 중심 피벗 바닥 0; 전체 예상 폭 약 5u·높이 3u. 중앙 문은 아치 안쪽, 바닥 앞의 얕은 계단과 양쪽 잔해를 붙인다.
- 봉인 조각 홈 세 개는 **빈 홈**이다. 밝은 완성 부적/열린 문으로 오해되지 않게 어두운 안쪽과 흐린 청색 테만 쓴다.
- 시각 GLB에 충돌·애니메이션 없음. 게임 쪽 `Stairs` 상호작용 노드를 남긴다. 1280×720 기본 아이소 카메라의 문턱 05/06, 접근 클릭 주행, 도호 실루엣으로 검수한다.

## 출처와 재현

`source/`는 빌드에 쓰는 승인 원본과 게임에 이미 들어간 GLB의 정확한 사본이다. 원본 경로는 각각 `joseon-assets/workbench/production/bg_concept_336/img/town_seal_gate.png`, `joseon/assets/models/props/{cave_arch,seal_door}.glb`이다. 비채택 `stairs_down`은 `joseon/assets/models/tilekit_stone/stairs_down.glb`에서 검토했고, 5MB 사본은 이 묶음에 중복 저장하지 않았다.

## QA와 반입 메모

- Godot 4.7.2 `model_check --kind=tile`: **9 메시·11,471 삼각형·4.37×3.07×5.26u**, 텍스처 1024² 두 장 + 256² 1장, 발 −0.07u. 12k 예산 안쪽이다. `RESULT WARN: 원점 치우침`은 오류가 아니라 **문 중심을 피벗**으로 정했기 때문이다. 앞쪽으로 이어진 디딤판 때문에 AABB 중심이 문보다 0.69u 앞에 있다.
- 중성 렌더 `preview/gate_neutral.jpg`. 게임 임시 배치에선 문 뒤쪽 바위와 앞쪽 디딤판이 이어져 읽힌다. `preview/before_threshold.jpg`·`after_threshold.jpg`는 같은 `town_approach` 고정 카메라의 원본/후보.
- 검수 때는 임시로 `TownDressing._gate`가 통합 GLB를 보이게 하고 기존 `DungeonEntrance`의 **시각 계단만** 숨겼다. 클릭 트리거와 봉인 안내는 그대로여서 `town_approach` 133검사, `town_exits` 8검사가 통과했다. 이 임시 코드는 게임 반입으로 확정한 것이 아니다.
- #344 실제 배치 시 `DungeonEntrance` 노드를 삭제하지 말고 원본 1m 계단 **시각 인스턴스만** 제거한다. 현재 `Stairs`의 푸른 OmniLight(세기1.8·반경4)가 빈 홈·발판을 다소 하얗게 태운다. 봉밀굴 잠긴 문에 한해 범위와 세기를 낮춰 세 홈과 클릭면을 다시 확인한다. 종이 씰의 원래 백색도 같이 볼 것.
