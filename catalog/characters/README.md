# 조선헌터스 캐릭터 자료관

정본은 `catalog.json`, 독립 조회본은 `index.html`, 대화용 축소 조회본은 `inline.html`이다. 승인과 현재 적용은 별도 상태다. 도호·마을 NPC 5명·구미호(주모/본체), 연관 인물 귀새·청연을 8인물/9형태/49자료로 수록한다.

2026-10-11 실측: 7개 현재 ModelDef 로드·중립 모델 렌더, NPC 5명의 실제 대화 화면과 도호 표시. 귀새·청연 및 구미호 구초상은 정의 존재와 실제 사용을 구분한다. 새 구미호 #741 v2는 톤만 승인, #742 H01은 추천이고 H01~H03 외형은 미승인이다. 현재 boss_gumiho는 흑랑 GLB를 참조한다. 새 원화가 반입된 것으로 표시하지 않는다.

전체 보드는 원본으로 보존하고 직접 확인한 좌표의 선택 부분을 미리보기로 보여준다. 현재 초상 atlas는 UI의 frame0/still_rect에 맞춘 파생 미리보기다. 모델 뷰어는 기본 조명/직교 zoom 4.5/yaw45/idle0초이며 마을 조명·배치 방향·EnemyDef tint와 다르다. 실제 월드 캡처는 동적 의존성이 완전하지 않아 최신성 판정 불가로 표시한다.

## 갱신

원화/반입/설정 변경 카드에서 정본 JSON과 근거를 갱신하고 `tools/character_catalogue.py --dry-run`으로 영향, `--check`로 경로·SHA·스키마·의존성을 검사한다. `--refresh-runtime`은 새 JSON에만 연결 인벤토리를 내보낸다. 승인과 과거 캡처는 자동 변경하지 않는다. 필요한 새 캡처를 보존한 뒤 viewer의 빌드 명령에 `--validation` 검사 JSON을 주고 재생성한다. 운영 전문은 게임 저장소 `docs/design/character_art_catalogue_ops.md`, 생성기 실행법은 `viewer/README.md`다.

원본과 정확 프롬프트·참조를 SHA 경로 또는 기존 저장소 경로+SHA+커밋으로 보존한다. `media/`는 원본 바이트를 Git에 그대로 기록하고 `previews/`는 파생 WebP다. 임시 생성 캐시나 작업트리는 정본 보관소가 아니다. 출력의 원본 링크는 로컬 경로이며 저장소를 옮기면 다시 빌드한다.

JSON 정본과 생성 HTML을 택한 이유는 원본·판정·현재 연결을 한 자료에서 검증하고 축소 화면을 반복 생성하기 위해서다. 문서마다 이미지를 수동 복사하는 방법은 중복·옛 상태 혼합 때문에 기각했다. 외형 일관성과 승인 판정은 사람의 확인 근거로 남기고 파일 해시로 승격하지 않는다.
