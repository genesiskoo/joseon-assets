# #498 원화 읽기 검수 · 후보 단계

개별1024 원본14장과 기존 승인 참격·돌진 베기·회오리 원화를 직접 보았다. 10종 후보의 그림 제작·반입을 완료했다고 판정하는 문서가 아니다. 원본별 생성 작업ID·요청·프롬프트·참조SHA는 원위치에 보존하고, 패킹의 기계 검증과 사람의 기능 검수를 나눴다.

보완4종을 골랐다. 부적 진은 인물/칼 대신 바닥의 큰 부적과 먹 원, 주머니는 작은 허리소품 대신 꽉 찬 천주머니 자체, 조식은 주변 부적/방어고리 없이 안정된 좌선 인물, 칼바람은 정지한 한 원 대신 옆으로 이어지는 큰8자 회전과 뻗은 다리를 보여 준다. 보완본의 실제 기능 모티브가 원본보다 명확하며, 다른6종의 원본은 선택을 바꾸지 않았다.

| 비교 | 원화에서 읽히는 차이 | 남은 작은 크기 확인 |
|---|---|---|
| 회오리 ↔ 칼바람 | 순간의 한 원 ↔ 옆으로 이어지는 두 회전 | 30px 두 고리 교차가 한 덩어리로 합쳐지는지 |
| 부적 흩뿌리기 ↔ 부적 비 | 전방 세 갈래 ↔ 수직 다섯 종이/빗살 | 인물보다 종이/궤적이 먼저 읽히는지 |
| 검 숙련 ↔ 찌르기 | 고정 그립·철검 ↔ 우상단 직선 공격 | 숙련은 얼굴/갓 면적이 커 손아귀가 약해질 수 있음 |
| 돌진 베기 ↔ 찌르기 | 낮은 수평 이동 몸 ↔ 고정 어깨에서 나가는 우상단 검 | 인물/뻗은 검을 공유해 궤적 방향이 충분한지 |
| 조식 | 좌선·아랫배 손·짧은 호흡 | 공격/보호막/부적 효과 없음 |
| 주머니 | 큰천주머니·빽빽한 종이다발 | 종이표식보다 수용량 모티브가 먼저 읽힘 |

도호 인물의 갓·남색 겹도포·흰깃·적갈색 띠, 먹붓/거친 마른붓 질감은 승인 A 참격과 이어진다. 도약 베기·찌르기에 요청하지 않은 장식 부적이 남아 있고, 연격의 두 옅은 보조궤적은 작게 줄이면 셋째타 리듬보다 한 번의 큰 베기로 읽힐 수 있다. 이 유보점은 `visual_review.json`에도 기록했다. 부적 진 보완의 바닥 표식은 낮은 타원보다 위에서 본 원에 가깝지만, 지면에 붙은 부적이라는 기능은 명확하다.

신규10 후보는 전체 정사각 그림을 128×128로 한 번 축소한 RGBA다. 배경이 불투명하므로 기존 승인3종의 알파 외곽과 슬롯에서 다를 수 있다. 원본에 없는 알파 제거/크롭/색 보정은 하지 않았다. 기존3종 PNG와 `UiSkin`/slot은 게임에서 바이트 그대로 복사해 독립 QA 프로젝트에서만 쓴다.

Native 검수 화면은 전체128, 이미지30/48/60, HUD30/p3·60/p5, 스킬48/p3을 나란히 보여 준다. `revisions`는 4개의 같은 슬롯 before/after만 담으며 새 반입 비교가 아니다. 패킹10종·원본14장·해시·RGBA128·기존3종은 `packing_qa.json` PASS, 독립 Godot 헤드리스 검증은 `native_qa/verify.raw.log`의 `GODOT_498_VERIFY_PASS`다. Native 캡처와 최종 PD 채택은 지휘 세션이 이어서 확인한다. 게임 반입 0종·전체 Unit/E2E 미실행(게임 코드 변경0)이다.

Sandbox import/verify 중 나온 엔진 환경 오류는 `native_qa/import.raw.log`·`verify.raw.log`에 원문 보존했다. 루트 인증서 저장소, 분리된 user:// 편집기 디렉터리, Steam 설치 경로의 편집기 설정 저장 권한 메시지가 있으며 스크립트 파싱 오류는 없다. 실행 PASS와 이 원문을 함께 전달한다.

Native 최초 시도에서 `overview`는 완료됐지만 `sizes_a`의 실제 `_draw`가 다음 오류로 끊겼다. 최초 콘솔·PNG는 지휘 세션의 `native_qa_root/original/`에 보존하며, 해당 `sizes_a` PNG와 뒤따른 CAPTURE_PASS는 무효다. 헤드리스 VERIFY는 그리기를 거치지 않아 이 오류를 검증하지 못했다. `indices` 조건식의 일반 배열→정수 배열 대입을 명시적인 `Array[int].assign()`로 고치고, 그리기 완료 표식과 런타임 Logger의 비경고 오류0을 확인한 뒤에만 PNG/PASS를 만들도록 보완했다. 지휘 세션이 새 `native_qa_root/original_attempt2/`에서 Native 네모드 재시도를 확인하기 전까지 작은 슬롯 검수는 완료로 판정하지 않는다.
