# #543 실제 보스 조우 검사 경계

최초 전체 실패 원문, 실제 조우 관측 focused 원문, 수정 후 전체 성공 원문과 검사 소스를 보존한다. 최초 실패에는 물리 틱 관측이 없으므로 0틱 경계 설명은 코드에서 도출한 추론이며 관측 사실로 단정하지 않는다. 수정 후에는 실제 물리 처리 한 틱으로 신호 1회·boss 컷인·정지가 열리고 Esc가 같은 전투로 복귀했다.

runtime·원화·11m 계약은 유지한다. 검사 대본의 대기만 최대 1초 조건 대기로 바꾸고 기존 26개 판정을 유지했다. 최종 성공 수와 원본 SHA는 verification.json에 기록한다. push는 수행하지 않았다.
