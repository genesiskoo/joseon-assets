**실제 해상도:** 히어로 원본 2206×713 → 최종 3840×1240은 기계 확대다. 네이티브 4K로 표기하지 않는다. 얼굴 안전 영역은 검수판으로 확인했지만 실제 Steamworks 업로드 후 클라이언트 미리보기는 PD가 확인해야 한다. B는 얼굴 하단 여유가 A보다 작다. 라이브러리 A 제목은 신발 끝 일부와 겹친다. 페이지 배경의 우측 인물 크기와 본문 가림은 계정 미리보기에서 최종 판정한다.

**검수판:** 01 헤더 A/B, 02 세로·라이브러리 A/B, 03 작은 캡슐 실제 크기 before/after, 04 히어로 안전 영역 before/after, 05 로고 before/after, 06 메인·페이지 배경. JPG 6장, 모두 1280폭·300KB 이하.

**추적:** `workbench/production/steam_art_622/plan.json`, `outputs.json`, `prompts/`, `raw/`, `exports/`. 내장 image_gen을 사용했고 정확한 백엔드 버전은 도구에 노출되지 않는다. 원본·최종 PNG SHA256, 실제 호출 참조, 프롬프트 해시와 미채택 상태를 기록했다. 원본 20장의 합 43,873,328 bytes (<50MB), 단일 원본/최종 파일 <10MB. 원본을 같은 카드로 추가 생성해 50MB 이상이 되면 #579 보관 규칙을 다시 적용한다.

**Steam AI 공개 메모:** 스토어용 키아트·로고 후보에는 생성 AI를 사용했다. 최종 공개 시 실제 채택 범위를 AI Content Survey에 기록한다. 생성 키아트는 게임 플레이 스크린샷으로 사용하지 않는다.

**왜 이 구성인가:** 공통 H1 외형과 로고를 고정하고 포즈·지역 분위기만 두 방향으로 비교하면 제목 가독성과 캐릭터 인상을 함께 판정할 수 있다. 한 장을 모든 비율에 잘라 쓰는 방식은 세로에서 갓/검이 잘리고 작은 캡슐에서 제목이 약해지므로 각 규격을 별도 생성했다. 확대·축소·중앙 미세 크롭만 로컬 도구로 처리했으며 새 인물이나 글자는 로컬 합성하지 않았다.
