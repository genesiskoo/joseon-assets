벨트는 물약만 두고 HUD에는 빈 부적 보유 수를 표시한다. 화염·빙결·벽력·진·비의 원소별 선택과 MP0 살풀이까지 13개 선택지를 실제 입력으로 확인했다. 새 선택기 촬영은 레벨30 검수 준비이며 이전 레벨6 사진과 DPS를 비교하지 않는다. 툴팁 사진은 화염에서 빙결 F4 선택으로 바뀐 상태다.

실제 창 선택기312검사·투척56검사와 최종 전체156개 시나리오가 통과했다. 연속 베기 후보를 포함한 결합 검수이며 두 카드의 PD 판정 후 착륙한다. 종료 진단은 별도 원문에 보존해 기능 PASS를 무경고로 표현하지 않는다. 공개 사진판에는 실행 raw·내부 경로·검증 메타데이터를 포함하지 않았다.
