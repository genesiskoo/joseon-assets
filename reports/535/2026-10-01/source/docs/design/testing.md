# design/testing.md — 자동 테스트 (단위 + e2e)

> D-055 "완료 = 정적 + 동적 2관문"의 동적 관문을 사람 없이 돌리기 위한 장치. 코드 정본 `tests/e2e/e2e_runner.gd`(오토로드) · `tests/e2e/e2e.gd`(시나리오 API) · `tests/e2e/scenarios/*.gd` · `tools/test.ps1` · `.github/workflows/tests.yml`.

## 1. 한 단락 사양

**두 층.** ① **단위** = `tests/test_*.gd`(`godot --headless -s`, 오토로드 없음, 순수 클래스만) — 기존 6개 유지. ② **e2e** = 진짜 게임을 부팅해 **로봇이 플레이**한다: `godot --headless -- --e2e=<이름|all>`이면 오토로드 `E2eRunner`가 켜져 시작 화면을 건너뛰고(저장은 `user://save_e2e.json`로 분리 — PD 저장 파일은 건드리지 않음), 시나리오를 차례로 실행한다. 시나리오는 `E2eScenario`를 상속한 스크립트 하나 = 대본 하나. 대본은 사람이 하는 동작 그대로 쓴다 — 클릭은 `Input.parse_input_event`로 **진짜 마우스·키 이벤트**를 넣어 플레이어·창의 입력 경로를 그대로 탄다(헤드리스에서도 카메라 좌표 변환·물리 레이캐스트·창 좌표 계산은 전부 돌아간다). 상태 확인은 `GameState`·노드를 직접 읽는다(`check(cond, "설명")`). 시나리오마다 새 판으로 리셋(새 캐릭터 + 조작 상태 `PlayerCombat.reset_session` + 고정 시드 `run_seed = 20260916` — 시드는 던전·스폰 배치만 고정하고 싸움 굴림은 매번 다르다 · 단 **도호의 공격은 늘 맞는다** = 명중 확정 `DamageCalc.sure_hit`, 명중률을 재는 밸런스 대본만 끔, 맨 아래 #342 절), 시간 제한 기본 60초(대본이 `timeout_sec()`로 늘린다). 대본의 시간 판정은 `t.game_time()`(= `GameClock.now`, 물리 델타의 합 — 경직·넉백·busy와 같은 시계, #234)으로 잰다 — 프레임 수로 세지 않고(헤드리스는 ~128fps, #97) 벽시계(`Time.get_ticks_msec`)로도 재지 않는다(고정 프레임 녹화·슬로모에서 어긋난다, #184·#234 — 벽시계는 실시간 것 = 소리 캡처·프레임 성능 계측에만). 결과는 `E2E <이름> PASS|FAIL (검사 n)` 줄 + 요약, 실패가 있으면 종료 코드 1. 창 모드(`godot -- --e2e=all --e2e-shots`)면 단계별 스크린샷을 `user://e2e/`에 남긴다(헤드리스는 그리지 않으므로 생략). 창 모드에서는 러너가 진짜 OS 커서를 게임 앞에서 막고 **대본이 넣은(표식 달린) 마우스만** 게임에 닿는다(맨 아래 #369 절). **못 보는 것** = 보기에 어색한 것(겹침·UI 미관) — 그건 PD 눈. **실행** = `tools/test.ps1`(단위 6 + e2e 전부, 로컬) / GitHub Actions `tests.yml`(push·PR마다, Linux 헤드리스). dev 키(`]`·`N`·`X`…)는 시나리오의 "셋업" 도구로 쓰되, 검사 대상 동작(픽업·장착·문·서낭단·매매·퀘스트·저장)은 반드시 실제 클릭 경로로 한다.

**소환 = `t.spawn_enemy` · 적 정의 = `t.enemy_def` (#416)** — 대본이 적을 세울 땐 `await t.spawn_enemy(def|id, pos, area_level, opts)`(씬 → def·레벨 → 층 `Enemies`에 붙임 → 자리 → 붙은 뒤 설정 → 2프레임, `opts` = scene·pack·rank+mods·hp·state·frozen·no_physics·disabled·frames), 정의는 `t.enemy_def("bandit")`(`E2e.ENEMY_DEFS` = bandit·bat·talisman_master·boss_heukrang) — `load("res://actors/enemy.tscn")`·`load("res://data/enemies/…")`를 대본이 직접 부르지 않는다. 대본만의 소환(정예 무리·우두머리·하수인 = `EliteSpawner.spawn_pack`)은 그대로.

**단위 10** = `tests/test_{balance,damage_calc,dungeon_gen,items,progression,save,town,models,audio,vfx}.gd` + `python tools/vfx_sheet.py --selftest`(이펙트 시트 도구, PIL 없으면 SKIP). `test_vfx`는 `tests/fixtures/vfx/probe_ring/`(셀프테스트 산출 픽스처)이 임포트돼 있어야 ③을 검사한다. 단위 대본의 합격 = 「fails=0 PASS」 줄 **과** 출력에 오류 줄(SCRIPT ERROR·Parse Error·Compilation failed·엔진 ERROR 줄) 없음 **과** 종료 코드 0 — 합격 줄이 있어도 오류 줄이 있으면 FAIL(#401), 오류 줄이 없어도 종료 코드가 0이 아니면 FAIL(#368, `testing_log.md`). 의도적으로 오류를 내는 시험(예: 망가진 지도를 거부하는 `test_dungeon_gen`)은 그 시험에만 거르는 허용 목록으로 구분하고, 전역 무시는 하지 않는다.

**도구 셀프테스트** (test.ps1 단위 층이 같이 돌림) = `vfx_sheet.py`·`audio_intake.py`·`board.py`·`sfx_gen.py`·`doc_budget.py`(#412 — 자동 import 세 문서 예산·STATE 줄 길이, 사양서 60KB 넘으면 WARN) + **`godot --headless -s tools/motion_audit.gd -- --selftest`**(#139, CI도) — 전투 동작 눈금의 계산식을 **답을 손으로 셀 수 있는 합성 동작**(골반 60ms 선행·감김 39.3°·낙차 0.15·잔심 0.26초·뾰족함 15, 모델 통째 360° 회전, 복귀 웅크림, 올라가며 베기)과 작은 진짜 뼈대(골반 180° 회전)로 검산한다. 새 눈금을 더하면 여기에 경우를 같이 넣는다. **`godot --headless -s tools/look_audit.gd -- --selftest`**(#121) — 외형 셈법(텍스처 × 틴트를 선형에서 곱함·단색 표면·면적 가중·투명 제외·텍스처 폭·밴드 판정·반입 id 추정)을 합성 표면의 손셈과 대조한다. 이어서 단위 층 끝에 **외형 표**(14가족 알베도 밝기·채도·텍셀 밀도)를 찍는데, 이 표는 **출력만** 한다 — 밴드 밖이 있어도 실패로 세지 않는다(PD 판정 전, 주간 리뷰 추세용 · `asset_pipeline_consistency_2026-09-21.md` §7).

**밀도 도구 셀프테스트** (#294 M8 — `godot --headless -s tools/dungeon_stats.gd -- --selftest`, 단위 층이 같이 돌림) — 길 따라 1분에 만나는 적(monsters_v2 §5.5)의 셈(길 길이 · 곡선 솎기 · 선분 거리 · 무리 어그로로 무리째 셈 · 분당 · 밴드 8~12/14~20 · 8방 최단 · 탐색 경로 · 방 칸 규칙)을 **답을 손으로 셀 수 있는 합성 필드(길 35칸 · 무리 셋)와 손 지도 던전(방 둘 · 복도 한 줄)**으로 검산하고, 흑랑 굴 1층 진짜 데이터로 셈이 돌고 결정적인지 본다. 지역 수치는 `-- --area=<id> [--per-seed]`로 찍는 표일 뿐(밴드 밖이어도 FAIL 아님 — 판정 몫).

## 촬영 전용 대본 (#455)

`--e2e=_slice_capture`는 못골 보행·할매 의뢰·들녘 탐험·굴 입장·던전 전투·흑랑·드랍/가방·스킬/장비를 순서대로 촬영한다. 게임 규칙과 수치는 바꾸지 않고 e2e 독립 세이브에 Lv6 준비 캐릭터를 세운다. 전투는 실제 자동공격·스킬·벨트 경로이며 명중 확정은 e2e 기본을 따른다. 클립 경계는 `CAPTURE <이름> BEGIN|END <렌더 프레임>`으로 남겨 로딩·촬영 준비를 제외하고 MP4로 자른다. `_` 접두어라 전체 회귀에는 포함하지 않는다. Godot Movie Maker로 고정30fps·1920×1080 영상/게임 소리를 함께 출력하고, 원본·MP4·raw로그·장면표는 joseon-assets reports/455에 보존한다. 기존 러너를 재사용하면 사용자 세이브와 실제 게임 입력·오류 검사 계약을 유지할 수 있어 별도 플레이 자동화 프로그램보다 재현성이 좋다.
