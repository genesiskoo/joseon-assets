# #621 스킬 아이콘 7종 — A/B 후보

PD 미채택, 게임 반입 0. 내장 image_gen으로 14개 첫 후보와 분신 A·부적 숙련 B 보정 2개를 만들었다. A/B 각 7종의 최종 지역 후보와 이전 버전을 보존한다. 실제 백엔드 버전은 도구에 노출되지 않는다.

원본은 1254×1254 불투명 PNG다. 내보낸 RGBA 파일의 alpha는 전부255이며, 실제 원본의 색 모드는 outputs.json에 기록했다. 게임 후보 128×128, 비교용64×64·40×40은 기계 축소다. 별도 테두리·문구가 없는 먹 바탕 정방형이며 UI가 테두리를 그린다. 참조는 H1 **왼쪽만** 도호 외형, #498 채택 slash 원본은 화풍·명암, breath는 몸 도술 톤, pouch는 황지/붉은 글 재질만 사용했다. 실제 호출 참조와 프롬프트·파일 SHA256은 outputs.json에 기록했다.

## 추천 혼합안 — 채택 아님

| ID | 스킬 | 후보 |
|---|---|---|
| blink | 축지법 | A_blink_r1 |
| light_step | 경공 | B_light_step_r1 |
| clone | 분신술 | A_clone_r2 |
| hide | 은형술 | A_hide_r1 |
| iron_body | 금강불괴 | A_iron_body_r1 |
| first_cut | 첫 칼 | B_first_cut_r1 |
| thunder_lore | 벽력부 익히기 | B_thunder_lore_r2 |

축지 A는 인물과 접힌 이동 흔적, 경공 B는 가볍게 딛는 발로 구분한다. 분신 A R2는 실제 본체 한 명과 먹 분신 두 명, 은형 A는 한 인물의 반쪽 소멸, 금강불괴 A는 기존 복장의 교차 팔 버티기다. 첫칼 B는 한 번의 큰 수직 내리치기, 부적 숙련 B R2는 종이/붉은 글 큰 형태를 선택했다. 이는 몸 도술·패시브의 **아이콘 상징**이며, 새로운 공격 도술·패시브 FX·금속 갑옷을 승인하지 않는다.

## 직접 검수와 남은 한계

- 128·64·40·34px을 같은 크기로 비교했다. 기존 #498의 먹색/무광/장색 결은 유지하지만, 새 후보의 잔먹 무늬가 더 많다. 특히 분신 후열과 축지의 땅 접힘은34px에서 약해지며 채택 후 실제 스킬창·HUD에서 마지막 판정을 한다.
- B 전체가 단순 기호만인 것은 아니다. 분신·금강불괴·첫칼에는 도호 인물이 남는다. A 부적 숙련은 쓰는 도호가 함께 나오고, B R2는 종이가 주인공이다.
- B 부적 R2에는 손끝3개가 보인다. 작은 붓끝은 요청했지만 구분되지 않는다. 이 한계를 숨기지 않고 후보로 남겼다.
- 분신 A R1의 밝은 후열과 큰 흰 곡선을 R2에서 먹색/조용한 바탕으로 보정했다. B 부적 R1의 큰 얼굴을 R2에서 제거했다. 기존 버전은 삭제하지 않았다.

## 검수판

## 반입 대기

PD가7개의 파일을 지정한 뒤 게임 `assets/ui/skills/<id>.png`로 복사하고 `data/skills/<id>.tres` icon을 지정한다. 기존 폴더 규약은 반입 시 다시 확인한다. Godot 임포트·전체 필수 검사·스킬창/HUD 실제 스크린샷을 실행하고 별도 게임 커밋으로 기록한다.

## 왜 이 구성인가

스킬 뜻과 기존 도호 외형을 먼저 고정하고 인물 중심/큰 형태 중심을 비교하면 작은 슬롯에서 능력 구분과 캐릭터 인상을 함께 판정할 수 있다. 한 도호 얼굴을 모든 능력에 재사용하는 방법은 몸 도술 구별이 약하므로 발·분신 수·반쪽 소멸·교차 팔·한 번의 검·황지를 각각 다른 큰 형태로 잡았다. 새 내용은 모두 내장 image_gen으로 만들었고 로컬 도구는 크기 변경과 검수판 배치만 수행했다.

AI 공개: 후보 원본은 생성 AI 사용 대상으로 기록한다. 실제 채택 파일 범위는 반입 이후 Steam AI 공개 목록에 옮긴다.
