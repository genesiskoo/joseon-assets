# #451 승인 가방 부적 최종 통합 검증

승인된 표적 UI를 현재 컷인·지역·스킬 코드에 통합했다. 원본 가방 물체를 표적 확정까지 유지하며 불·벼락은 적, 한기는 바닥을 고른다. 실제 시전 시작에 한 장을 소비하고 취소·창·지역·사망·입력 버퍼 경계를 재검증했다.

최초 전체 검사에서 드러난 실제 불가살이 화로 끼임은 #535에서 처리했고, 흑랑의 초기 private 스트림 고정은 #536 fixture 초안에 반영했다. 이어 발견된 컷인 검사 대기의 물리 경계는 #543에서 실제 조우를 기다리도록 수정했다. 그 다음 전체116종은 통과했지만 #536의 Lv3 파수 난수 소비와 실제 빗나감1회 차이는 아직 남았다. 읽기 감사 뒤 후속 rebase/구현이 자동 승인에서 두 번 거절되어 직접 승인을 요청했다. 기존raw50개·소스·차이 대조·거절 전달 원문·미적용 검토안을 related_536에 보존하며 #536 완료를 주장하지 않는다. 기존 게임 수치·승패 판정은 유지했다. 실패 원문을 삭제하지 않고 최종 통합 전체 성공 로그와 나란히 보존한다.

전체 검사 수와 테스트한 main은 verification.json에 기록한다. 이 자료는 신규 아트 채택을 뜻하지 않는다. 기존 승인 전후6JPG와 원본 검수 reports/451/2026-09-27을 유지했다.
