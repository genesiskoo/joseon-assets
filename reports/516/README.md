## 제작 판단

PD의 새 방향은 구미호가 사람 사이에 오래 섞여 살았다는 설정을 외형으로 보여 준다. 따라서 평소에는 꼬리와 장신구를 숨기고, 홀림은 눈맞춤·입매·손목·몸의 기울기로 표현한다. 기존처럼 늘 화려한 보스로 보이게 하는 대안은 잠입 설정을 약하게 만들어 이번 탐색의 주력에서 제외했다. 정체가 드러난 뒤에도 앞치마와 낡은 저고리를 남기면 전후가 같은 인물로 보인다.
