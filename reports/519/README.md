# 구미호 주막 안주인 — 1페이즈 야성 보스 원화 (#519)

2026-09-30. #516에서 PD가 고른 **C 주막 안주인**과 그 정체 공개 C5를 같은 인물로 이어, 최종 보스 **1페이즈** 전투 모습을 Comfy Cloud `ByteDanceSeedreamNodeV3` / `seedream 5.0 pro`로 탐색했다. 이 시안은 PD 검토 전이며 게임 모델·기존 승인 F01/F03를 자동으로 교체하지 않는다.

## 해석

현행 전투 사양 `docs/design/monsters_v2.md`의 구미호 P1은 **물리**, P2는 불·영기, P3는 살이다. 그래서 1페이즈는 불꽃·영기 발광보다 **낮은 포식 자세, 발톱, 손목과 어깨의 털, 바닥을 쓰는 무거운 꼬리**에 힘을 준다. 남색 저고리·치마·앞치마·소박한 신발과 얼굴을 남겨 주막 안주인에서 변한 것이 읽히게 한다. 왕후복·장신구로 격을 올리는 대안은 생활인 정체와 전후 연속성을 깨므로 쓰지 않았다.

| 시안 | 장면과 실루엣 | 직접 검수 |
|---|---|---|
| `P1A` | 깨진 잔 앞에 네 발처럼 낮게 웅크린 덮치기 직전. 찢어진 면 소매·털·발톱 | 물리 공격성과 주막 안주인의 얼굴이 가장 균형적. 꼬리 9가닥·뿌리 분리는 불명확 |
| `P1B` | 아이소메트릭에 가까운 높은 시점, 앞치마 끈을 쥔 채 다가옴 | 화면 축소 실루엣·얼굴 인지가 좋음. 얼굴은 아직 말끔하고 꼬리가 장식 부채처럼 모임 |
| `P1C` | A를 참조해 비녀가 풀리고 눈썹·입매·팔 털을 더 짐승답게 변형 | 야생성 가장 강함. 얼굴 연기가 과장되면 기존의 은근한 홀림과 멀어질 수 있음. 꼬리 뭉침 지속 |

`gumiho_C5_reference.png`는 #516 `gumiho_boss_516_C5_00001.png`를 복사한 단일 인물 입력이다. P1A·P1B는 C5를, P1C는 P1A를 참조했다. 세 출력은 모두 `2304×1728` 2K. 동명 `.api.json`에는 실제 제출 그래프와 정확한 프롬프트·모델·시드, `.job.json`에는 작업 ID·입력/출력 SHA256과 업로드 이름을 기록했다. API 키는 저장하지 않았다.

**다음 검수:** 콘셉트의 꼬리는 아홉 가닥으로 정확히 셀 수 없고 골반 뿌리도 겹친다. PD가 1페이즈 얼굴·자세 강도를 고르면, 모델용 정면·측면·후면에서 꼬리 9개의 시작점·길이·충돌 범위와 손·발 자세를 별도 설계한다. 그림의 표정과 발톱은 3D 아이소 시점에서 축소 검수해야 한다.

## 도호 H1과 같은 바닥에 둔 2샷 — PD 피드백 반영

PD는 P1A/B/C가 잡몹 수준이라고 판단했다. 원인을 장식·꼬리 수의 부족만이 아니라 **도호와 비교했을 때 신체 크기와 움직임의 위계가 없는 것**으로 보고, 승인된 도호 H1을 왼쪽, 같은 주막 안주인 구미호를 오른쪽에 놓은 16:9 전투 구도를 다시 만들었다. 두 인물의 발을 같은 바닥선에 두어 원근 착시로 몸집을 부풀리지 않도록 지시했다. 화염·영기 발광은 P2 이후에 남겼다.

| 시안 | 보스 읽힘 | 직접 검수·남은 문제 |
|---|---|
| `P1D` | 낮게 웅크린 거대한 인체와 사방을 차지한 꼬리, 도호 옆에서 위압감 상승 | 같은 얼굴·저고리·앞치마가 분명하다. 몸 자체는 커진 인간형이고 꼬리 끝이 잘려 아홉 가닥을 셀 수 없다. |
| `P1E` | 일어선 신장·팔 도달 거리 강조 | 크기는 크지만 긴 치마를 입은 거인으로 읽혀 변신의 파격이 약하다. 비교 실험으로 보관, 검토 JPG 슬롯은 쓰지 않는다. |
| `P1F` | 도호가 칼을 겨누는 자세와 낮은 보스 공격선 | 얼굴의 묘한 웃음과 덩치가 살아있다. 네발 짐승의 척추·뒷다리 구조를 요구했지만 출력은 여전히 거대 인간형에 가깝다. |
| `P1G` | 얼굴만 참조해 낮고 긴 네발 여우 몸통·높은 등·큰 발을 만든 실험 | 도호 대비 몸 길이와 공격 범위, 사람 얼굴의 주막 안주인 연속성이 가장 강한 보스 실루엣. 그러나 꼬리는 아홉 가닥/한 뿌리로 셀 수 없고 폐허 마당이 구미원 실내와 다르다. 앞치마가 배 아래 조각으로만 남아 3D에서 의상 연속성을 다시 잡아야 한다. |

`doho_H1_reference.png`는 승인된 `sheets/approved-2026-09-17-h1/K2_H_doho_hero_options.png`의 H1만 자른 입력이다. P1D/E/F는 P1C 전신을 구미호 입력으로, P1G는 `gumiho_P1C_face_reference.png`의 얼굴만 구미호 입력으로 썼다. 모든 2샷은 Comfy Cloud `ByteDanceSeedreamNodeV3` / `seedream 5.0 pro`, 2K `2848×1600`. 각 시안의 `.api.json`·`.job.json`에 실제 프롬프트·시드·작업 ID·입출력 SHA256을 기록했다. 이 생성 원화는 채택 전 콘셉트이며 기존 인게임 모델을 교체하지 않는다.

**제작 영향:** P1G처럼 비인간형을 채택하면 현재 인간형 리깅·애니메이션 재사용이 어렵다. 3D로 옮기기 전에 몸 길이·관절 수·꼬리 9개 뿌리와 휘두르기 범위·아이소 카메라 판독·보스 충돌체를 설계해야 한다. 전신 원화는 구조 제안일 뿐, 손발 개수와 정확한 아홉 꼬리를 증명하는 모델 시트는 아니다.
