# 구미호 주막 안주인 — 1페이즈 야성 보스 원화 (#519)

2026-09-30. #516에서 PD가 고른 **C 주막 안주인**과 그 정체 공개 C5를 같은 인물로 이어, 최종 보스 **1페이즈** 전투 모습을 Comfy Cloud `ByteDanceSeedreamNodeV3` / `seedream 5.0 pro`로 탐색했다. 이 시안은 PD 검토 전이며 게임 모델·기존 승인 F01/F03를 자동으로 교체하지 않는다.

## 해석

현행 전투 사양 `docs/design/monsters_v2.md`의 구미호 P1은 **물리**, P2는 불·영기, P3는 살이다. 그래서 1페이즈는 불꽃·영기 발광보다 **낮은 포식 자세, 발톱, 손목과 어깨의 털, 바닥을 쓰는 무거운 꼬리**에 힘을 준다. 남색 저고리·치마·앞치마·소박한 신발과 얼굴을 남겨 주막 안주인에서 변한 것이 읽히게 한다. 왕후복·장신구로 격을 올리는 대안은 생활인 정체와 전후 연속성을 깨므로 쓰지 않았다.

| 시안 | 장면과 실루엣 | 직접 검수 |
|---|---|---|
| `P1A` | 깨진 잔 앞에 네 발처럼 낮게 웅크린 덮치기 직전. 찢어진 면 소매·털·발톱 | 물리 공격성과 주막 안주인의 얼굴이 가장 균형적. 꼬리 9가닥·뿌리 분리는 불명확 |
| `P1B` | 아이소메트릭에 가까운 높은 시점, 앞치마 끈을 쥔 채 다가옴 | 화면 축소 실루엣·얼굴 인지가 좋음. 얼굴은 아직 말끔하고 꼬리가 장식 부채처럼 모임 |
| `P1C` | A를 참조해 비녀가 풀리고 눈썹·입매·팔 털을 더 짐승답게 변형 | 야생성 가장 강함. 얼굴 연기가 과장되면 기존의 은근한 홀림과 멀어질 수 있음. 꼬리 뭉침 지속 |

`gumiho_C5_reference.png`는 #516 `gumiho_boss_516_C5_00001.png`를 복사한 단일 인물 입력이다. P1A·P1B는 C5를, P1C는 P1A를 참조했다. 세 출력은 모두 `2304×1728` 2K. 동명 `.api.json`에는 실제 제출 그래프와 정확한 프롬프트·모델·시드, `.job.json`에는 작업 ID·입력/출력 SHA256과 업로드 이름을 기록했다. API 키는 저장하지 않았다.

**다음 검수:** 콘셉트의 꼬리는 아홉 가닥으로 정확히 셀 수 없고 골반 뿌리도 겹친다. PD가 1페이즈 얼굴·자세 강도를 고르면, 모델용 정면·측면·후면에서 꼬리 9개의 시작점·길이·충돌 범위와 손·발 자세를 별도 설계한다. 그림의 표정과 발톱은 3D 아이소 시점에서 축소 검수해야 한다.
