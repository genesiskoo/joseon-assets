**PD 채택 — 2026-10-01:** 구미호 후속 원화의 제작 모델은 **Comfy Cloud GPT Image 2.5 flare**로 고정했다. P1~P5 중 최종 컨셉은 아직 선택 전이다. P1 복식 + P5 낮은 자세는 추천 조합이며 확정안이 아니다. Grok·Seedream 산출물은 비교 기록으로 보존한다. [모델 채택 기록](model_selection.json).


**최신 PD 지시 — 2026-10-01:** 각 모델별 컨셉아트 5장. 선택한 C 주막 안주인의 눈빛과 인간형, 자연스러운 한 벌의 복식 구조를 유지하며 다섯 방향을 비교한다.

GPT Image 2.5 flare(P1~P5) · Grok Image 2.0(G1~G5) · Seedream 5.0 Pro(S1~S5), **모두 Comfy Cloud**, 신규 원본 총 15장 / 1664×2496. 같은 번호는 같은 프롬프트·얼굴 입력이다.

각 카탈로그는 새 시안 5장과 얼굴 참조 1칸으로 구성한다. 마지막 참조 칸을 신규 시안으로 세지 않는다.

|---|---|

| 4 | 젖은 앞치마의 무게 |
| 5 | 낮은 인간형 포식 자세 |

GPT 후속 컨셉 후보는 P1의 자연스러운 복식, P5의 낮은 인간형 자세, P3의 술잔 접객 연출이다. P1 복식 + P5 자세를 추천 조합으로 제안하며 개별 컨셉은 PD 선택 전이다.

P4는 신발이 세 개 보이는 해부학 오류가 있다. S1·S2·S4·S5는 짧은 상의/허리 노출/가슴 띠로 복식 기준을 놓쳤고, S4는 앞치마를 잡는 동작도 누락했다. 여러 시안의 발끝이 잘렸으며 모든 시안의 꼬리 9가닥 분리와 뿌리 연결, 후면·아이소 판독·3D 구조는 미확정이다.

왜 이 구성인가: 자세·여밈·옷의 손상 원인을 함께 바꾼 다섯 방향을 동일 번호로 세 모델에 전달하여 디자인 선택과 모델 차이를 함께 비교한다. 같은 자세의 무작위 변형만 다섯 장 만드는 대안은 선택 근거가 약하므로 사용하지 않았다.
