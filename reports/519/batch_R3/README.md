본색의 자연스러운 복식과 매혹은 P1, 낮은 인간형 실루엣은 P5, 주모가 술잔을 권하며 정체를 드러내는 연출은 P3·G3를 우선 추천한다. 앞치마 당김과 천의 연결은 G4가 좋다. 2026-10-01 PD 채택 이후 현재 본색 기준은 P1 복식 + P5 자세이며 P3는 보조 참고다. 나머지는 비교 이력이다.

P4는 신발이 세 개 보이는 해부학 오류가 있다. S1·S2·S4·S5는 짧은 상의/허리 노출/가슴 띠로 복식 기준을 놓쳤고, S4는 앞치마를 잡는 동작도 누락했다. 여러 시안의 발끝이 잘렸으며 모든 시안의 꼬리 9가닥 분리와 뿌리 연결, 후면·아이소 판독·3D 구조는 미확정이다.

`plan.json`·`prompts/`은 사양/실제 공통 제출문, `node_schema.json`은 당일 Cloud 노드 설정, 동명 `.api.json`·`.job.json`은 실제 그래프·작업 ID·입출력 해시, `report.json`은 전체 검수와 실행 기록이다.

초기 15개 제출 중 3개는 공급자 HTTP 429로 실패했다. `attempts/`에 실패 원문·기존 ID를 보존하고, 기존 큐가 모두 종료된 뒤 동일 프롬프트로 실패 건만 한 번씩 순차 재시도했다. 최종 이미지 15장과 총 제출 18건을 구분한다. 이번 생성에서는 콘텐츠 거절을 관찰하지 않았다.

본색 원화 방향은 PD 채택 완료다. 정확한 아홉 꼬리·후면·손발·아이소 판독은 후속 검수이며 3D 제작·게임 반입·main 착륙은 아직 수행하지 않았다.
