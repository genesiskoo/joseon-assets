# Joseon Hunters Style Bible v6 — 도호 H1 선택·K2 한국풍

## 현재 도호 선택 — H1 (D-071)

PD **“h1으로 가자”**. [승인 원본·선택 manifest](../sheets/approved-2026-09-17-h1/SELECTION.md)의 **왼쪽 H1**만 도호 정본으로 사용한다. H2/H3/R1/R2는 미채택. D-068의 도호 D03 부분을 갱신하며 귀새 G02·청연 C01·구미호 F01/F03는 유지한다. 후속 제작은 H1의 능청스러운 얼굴·어깨 위 검·갈라진 남색 겹도포·붉은 허리끈·푸른 패를 참조하고 생성 후 검수한다. 실제 GLB 반입은 별도다.

## 후속 제작 지시 — K2·주인공 위계·생성 후 검수

PD “조금 더 한국느낌” → “k2스타일에서…플레이어 캐릭터랑 구미호까지” → “주인공이…그냥 NPC같어” → “기존 버전의 복장디자인 좀 차용해. 그리고 이미지 생성되면 검증한번 돌려”.

- **화풍 = K2**의 한국 만화풍 얼굴·선·큰 무광 명암. [K1/K2](../workbench/production/korean-character-refinement-2026-09-17/README.md). NPC B의 역할·연령·능청은 유지하며 얼굴 구조와 복식은 재탐색할 수 있다.
- **주인공 위계:** 같은 화풍 안에서 PC는 큰 겹옷 실루엣·무기·얼굴 주변 대비·대표 장식으로 구분한다. 도호는 선택된 H1의 겹소매·갈라진 옷자락·붉은 허리끈·푸른 패를 우선한다. 기존 D03/R2의 촘촘한 문양·장신구를 H1에 자동 혼합하지 않는다.
- **생성 후 검수:** 정체성/복식, K2 화풍, PC/NPC 위계, 한국적인 인상, 손·검·사지·프레임을 직접 대조한다. 보정한 부분과 회귀 오류를 다시 확인하고 잔여 차이도 남긴다. 원화 검수와 실제 3D·인게임 검증은 구분한다.
- [PC·구미호·H안·R1/R2와 검수](../workbench/production/k2-player-gumiho-2026-09-17/README.md). H1만 채택됐으며 R2의 원화 검수는 탐색 이력으로 보존한다. 다른 캐릭터의 K2 신규 시안·게임 GLB를 일괄 승인한 것은 아니다.
- D-070의 어두운 무광 팔레트·실제 게임 재질 기준은 아래대로 유지한다.

## 현재 지시 — D-070

PD: “다크판타지인데 너무 밝은것 같음. 지금 제작되는 3d에셋이나 인게임이랑 결을 같이 가야됨”

**시각 바탕은 현재 3D 에셋·인게임과 연결되는 조선 다크 판타지.** 도호의 능청·여유와 B NPC의 개성, D-037의 swagger·그루브 인물 연출은 유지한다. D-037의 다크 판타지 명칭 금지는 최신 PD 지시와 D-070으로 갱신됐다.

## 참조 우선순위

1. **현재 실제 3D 렌더와 인게임**: 색·명암·재질·형태 복잡도·장식 밀도·게임 시점과 크기의 기준. [동결 캡처·소재·시안](../workbench/production/ingame-tone-alignment-2026-09-17/README.md). 캡처는 2026-09-17 05:00 KST 기준이며 이후 실제 자산이 바뀌면 다시 확인한다.
2. **NPC B1·B2·B3 전체**: [선호 원본](../workbench/production/npc-variants-2026-09-17/NPC_B_expressive.png). 연령·표정·역할 실루엣을 계승하고 얼굴 구조는 최신 K2 방향으로 조정할 수 있다. B1의 넉넉함 / B2의 가는 얼굴·능청 / B3의 엄격함. 밝은 조명과 촘촘한 문양까지 계승하지 않는다. S2 셀 애니형은 B 세트가 아니다.
3. **D-068·D-071 외형 정본**: 도호는 [H1 승인 보드 왼쪽 열](../sheets/approved-2026-09-17-h1/SELECTION.md), 귀새 G02·청연 C01·구미호 F01→F03는 [기존 승인 카탈로그](../sheets/approved-2026-09-17/SELECTION.md). 선택된 형태·대표 복식·소품을 따르며 도호 구 D03은 이력 참조다.
4. 모델 생산은 D-069 Meshy 이미지 경로·리깅·Mixamo를 따른다. 새 시안이 승인 외형이나 게임 GLB를 자동 교체하지 않는다.

## 공통 시각 언어

- 한국 시각 어휘: 한복·도포·흑립·갓·부채·방울·부적·목재·기와·큰 석재·한국식 격자. 조선풍 가공 세계이며 시대 고증 의무는 없다.
- 팔레트: 먹색, 깊은 남색, 회녹/회갈 석재, 그을린 갈색, 탁한 상아색. 탁한 적색·청록·오래된 금속은 식별점으로 제한한다. 새 HEX 락은 없다.
- 형태·재질: 아이소 카메라에서 읽히는 큰 색면과 실루엣. 무광으로 손으로 칠한 듯한 천·가죽·돌·목재, 소수의 큰 주름·이음선·모서리. 반복 자수·장신구·실사 미세 질감으로 품질을 대신하지 않는다.
- 얼굴: B의 표정과 나이 차이를 유지하되 실제 모델과 연결되는 단순한 면·선으로 정리한다. 밝은 도자기 피부나 과도한 눈 광택을 줄인다. 분위기를 어둡게 만든다는 이유로 모두 무표정하게 바꾸지 않는다.
- 조명: 통합 장면은 낮은 환경광과 제한된 국소광. 그림자가 깊어도 얼굴·손·검·이동면은 읽혀야 한다. 넓은 파스텔 채광·황금빛 햇살·전면적 광택을 기본으로 쓰지 않는다.
- 일관성: PC·NPC·배경의 재질 처리·빛 방향·접지를 공유한다. 배경의 정보량은 인물 가독성을 돕도록 제한한다. NPC에 도호의 장식을 복제하지 않는다.

## 제작용 시트와 장면 원화

- **3D 입력**: 중립 배경·중립 조명에서 고유색과 형태가 보이는 자세/다중시점. 어두운 장면 그림자·림라이트를 기본 텍스처에 굽지 않는다.
- **장면/키아트**: 실제 게임 카메라·캐릭터 크기·무광 재질·낮은 환경광을 출발점으로 국소 조명을 설계한다.
- **공통 프롬프트**: [ingame-tone.md](prompts/ingame-tone.md)를 우선 적용한다. 기존 common.md의 ambient-dominant fill은 통합 장면에 일괄 적용하지 않는다.

## 실제 자료를 사용할 때

- 마을의 임시 박스·캡슐, 모델 뷰어의 체커 바닥, 디버그 UI, 투명도 점무늬는 미술 기준으로 복제하지 않는다.
- 실제 Godot 캡처와 AI 생성 목표 시안을 항상 구분한다.
- 모델 뷰어의 clean 도호와 캡처 시점 게임에 사용된 도호를 혼동하지 않는다.
- 시안의 새 계단·등불·봉인 균열·소품이 이미 구현된 것처럼 기록하지 않는다.
- 캐릭터 제작 입력과 장면 원화의 사용 목적을 명시하고, 원본 참조·프롬프트·실제 크기·복사 해시를 보존한다.

## 피할 표현

- 한 인물만 사진 피부, 다른 인물은 애니 얼굴인 매체 불일치.
- 광택 플라스틱/과한 PBR, 큰 bloom·halo·광선, 작은 화면에서 소음이 되는 반복 문양.
- 형태가 읽히지 않는 검은 덩어리, 미세한 때·주름만 늘린 어둠.
- 한국적 정체성을 압도하는 타 문화 단독 복식이나 현대 총기·차량·거리 복장.
