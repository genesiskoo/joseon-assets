# Joseon Hunters Style Bible v3

**2026-09-17 PD 선호 방향: 기존 NPC B1·B2·B3 전체.** “B세트가 전체적으로 괜찮은데?”의 대상을 “이전 NPC 시트 — B1·B2·B3”로 명시 확인했다. S2 셀 애니형을 뜻하지 않는다. [NPC B 원본](../workbench/production/npc-variants-2026-09-17/NPC_B_expressive.png)의 얼굴 구성·가는 선·매트한 명암을 기준으로 PC·배경을 맞춘다. [B 기반 후속 2장](../workbench/production/npc-b-style-followup-2026-09-17/README.md)은 제작 후보이며 정본·게임 자산 교체 승인은 별도다.

## 목표

조선풍 가공 세계의 **조선 그루브 판타지**를 그린다(D-019/D-037). 능청스러운 인물과 경쾌한 액션이 기본이다. PC·NPC·배경이 한 화가의 작품처럼 이어지도록 얼굴 구성, 선, 명암, 재질 밀도를 공유한다. 키아트·캐릭터·배경 원화와 3D 제작 참고를 대상으로 하며, 캐릭터·타일의 최종 게임 자산은 D-066/D-067의 3D GLB 파이프라인을 따른다.

## 현재 지시와 우선순위

- **2026-09-17 최신 PD 지시: “주인공 스타일을 앵커로 안잡아도 되니까 변화를 좀 줘봐”.** 기존 도호 그림체를 공통 화풍의 필수 기준으로 삼지 않는다. 도호도 NPC·배경과 함께 새 화풍으로 바꿔 탐색한다.
- D-068 [승인 카탈로그](../sheets/approved-2026-09-17/SELECTION.md)의 도호 D03 / 귀새 G02 / 청연 C01 / 구미호 F01→F03는 현재 외형 정본이다. 탐색에서는 역할·복식·시그니처·식별색을 유지하며 얼굴 비례·선·채색·질감은 변주할 수 있다. 새 시안이 정본을 자동 대체하지 않는다.
- “npc+pc+배경 그림스타일이랑 톤 맞춰야됨”은 계속 적용한다. **한 방향 안의 일관성**을 맞추되 **서로 다른 방향 간의 화풍 변화**는 허용한다.
- [S1 먹선 / S2 셀 애니 / S3 붓질 세트](../workbench/production/world-style-exploration-2026-09-17/README.md)는 최신 미선택 탐색 후보다.
- 기존 [D03 기반 NPC 보정 세트](../workbench/production/npc-style-alignment-2026-09-17/README.md)와 [NPC A/B/C](../workbench/production/npc-variants-2026-09-17/README.md)는 이전 탐색 분기다. 해당 작업의 가는 선·큰 피부 명암 규칙을 새 시안 전체에 강제하지 않는다.

## 화풍과 무관하게 유지할 원칙

- 한국 시각 어휘: 한복·도포·갓·흑립·비녀·노리개·부적·목조건축·기와·장승·산성·사당. 시대 고증은 의무가 아니다.
- 인물의 연령·역할을 구분한다. 노인을 일괄적으로 젊게 만들거나 아동 비율로 줄이지 않는다.
- 인물 식별색을 유지하되 선택 화풍에 맞춰 채도·명도를 조정할 수 있다. 새 HEX 락은 만들지 않는다.
- 한 장면 안의 얼굴·손·옷·소품·건축·식생에 같은 묘사 원리를 적용한다. PC는 애니, NPC는 실사인 혼합을 피한다.
- 한 장면의 광원 방향·색온도·접지 그림자를 맞춘다. 배경의 디테일과 대비는 인물의 가독성을 돕도록 조절한다.
- 주인공의 장신구 복잡도와 NPC의 소박함은 달라도 된다. NPC에 도호의 문양·장신구를 복제하는 것은 그림체 통일이 아니다.
- 질감은 선택 매체의 표현으로 쓴다. S1의 인쇄/먹선 질감과 S3의 붓질은 탐색할 수 있으며, 실사 모공·주름·천 노이즈를 노인에게만 몰아 별도 화풍으로 만들지 않는다.

## 현재 비교할 세 방향 — 미채택

| 코드 | 얼굴·선 | 채색·재질 | 배경 |
|---|---|---|---|
| S1 먹선 그래픽형 | 각진 형태, 굵기 변화가 큰 먹선 | 제한색, 큰 검은 그림자, 부분적 인쇄 질감 | 건축·수목도 그래픽 형태 |
| S2 따뜻한 셀 애니형 | 둥글고 표현적인 성인 얼굴, 정돈한 선 | 밝은 색, 단순한 셀 명암 | 형태를 단순화한 따뜻한 마을 |
| S3 거친 붓질형 | 선보다 면으로 얼굴 구성 | 큰 불투명 붓질, 끊긴 경계, 색면 명암 | 인물과 같은 붓으로 그린 건축·식생 |

어느 방향도 아직 승인되지 않았다. 세부 장신구, 얼굴, 배경 밀도는 선택 이후 다시 검수한다.

## 금지 방향

- 무속 공포나 무겁고 처참한 인상을 기본 톤으로 삼는 것.
- 한국적 정체성을 압도하는 사무라이 갑옷·선협식 복식·서양 플레이트 아머, 현대 총기·차량·거리 복장.
- 과한 bloom·lens flare·림라이트·네온 외곽선·의미 없는 마법진.
- 한 인물만 사진 피부 또는 광택 PBR 재질을 사용하는 식의 매체 불일치.

## 참조 이미지 운영

1. 새 화풍 탐색은 이미지 입력 없이 외형을 문장으로 옮길 수 있다. 기존 도호 그림을 자동으로 스타일 참조에 넣지 않는다.
2. 참조를 쓸 때는 입력별로 렌더링 기준과 외형/구도 참고 역할을 구분한다. 도호는 외형 참고일 수 있으며 스타일 권한을 자동 부여하지 않는다.
3. 이번 세 방향은 공통 등장인물과 장소를 써서 비교했다. 사용자 선택 이후 선택 화풍으로 얼굴 → 전신 → PC·NPC·배경 통합 장면을 검수하고 확장한다.
4. 이전에 실사풍으로 실패한 15번 NPC와 U01은 이력으로만 보존한다. 새 스타일의 기준 이미지로 사용하지 않는다.
5. 새 결과는 workbench에 보존한다. 사용자 선택 전에 공식 자산을 덮어쓰거나 승인 플래그를 올리지 않는다.

## 공통 프롬프트 핵심

```text
Create the protagonist, NPCs and environment in one coherent chosen medium. The existing protagonist illustration is not a mandatory style anchor. Preserve recognizable roles, Korean costume signatures and identifying colors, while redesigning facial construction, proportions, contour treatment, shadow shapes and texture together. Keep distinct adult ages and expressive personalities. Use the same drawing or painting logic on faces, hands, cloth and scenery. Match light and grounding, and organize background detail to support the cast.
```

## 직접 검수

- 기존 도호 화풍을 바꾸라는 지시가 도호의 얼굴·선·명암에도 반영됐는가.
- 같은 장면의 PC/NPC 얼굴이 한 화풍이며 연령·역할·표정이 유지되는가.
- 인물과 배경이 같은 매체로 그려졌는가. 광원·접지·디테일 계층이 자연스러운가.
- 여러 후보의 차이가 단순한 색보정이 아니라 얼굴 구성·선·명암·붓질에서도 보이는가.
- 작은 게임 크기로 번역할 색 덩어리·실루엣인가. 원화 생성만으로 3D 반입 검증을 통과한 것으로 보지 않는다.
