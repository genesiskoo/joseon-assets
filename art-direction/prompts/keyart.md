# Key Art Prompt Template v1

## 용도

프로모션, 스토어 이미지, 랜딩 페이지, 챕터 대표 이미지용 키아트를 만든다.

## Reference Set

- style-ref: approved style anchor 1장
- character-ref: 등장 캐릭터 승인본 1~3장
- environment-ref: 배경 또는 지역 앵커 1장

## Template

```text
[COMMON_PROJECT_STYLE_BLOCK]
[REFERENCE_ROLE_BLOCK]

Create a cinematic key art illustration for Joseon Hunters, [SCENE_THEME].

Hero group:
- Main character: [CHARACTER_A_ROLE_AND_ACTION]
- Secondary character: [CHARACTER_B_ROLE_AND_ACTION]
- Third character or antagonist: [CHARACTER_C_OR_ENEMY]

Scene:
- Location: [LOCATION]
- Mood: [MOOD]
- Story moment: [ONE_SENTENCE_STORY_BEAT]
- Visual hierarchy: main character first, antagonist or supernatural threat second, environment third.

Composition:
- Strong triangular composition.
- Clear face and silhouette readability for the main characters.
- Leave negative space for title or UI crop on [TOP_OR_SIDE].
- Keep lighting dramatic but not glossy; use restrained rim light and atmospheric depth.

[OUTPUT_DISCIPLINE_BLOCK]
[NEGATIVE_BLOCK]
```

## Review Checklist

- 썸네일에서도 주인공과 위협 요소가 바로 읽히는가
- 기존 캐릭터 승인본과 얼굴, 의상, 무기가 맞는가
- 배경이 홍보용 밀도는 가지되 캐릭터를 잡아먹지 않는가
- 타이틀, 로고, UI 배치 여백이 있는가
