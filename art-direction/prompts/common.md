# Common Prompt Blocks v1

## Project Style Block

```text
Joseon dark fantasy action RPG concept art, late Joseon dynasty Korean visual language, painterly but readable game production art, matte surfaces, controlled brush texture, clean silhouettes, low-saturation ink black, deep navy, muted crimson, aged gold accents, weathered wood and paper talismans, soft atmospheric lighting, ambient-dominant fill, almost no rim light, no hard edge glow, no backlit outline, no glossy 3D rendering, no cyberpunk neon, no modern clothing, no Western plate armor.
```

## Reference Role Block

Use this block whenever reference images are attached.

```text
REFERENCE ROLES
- Image 1: project style anchor. Use palette, brush texture, lighting discipline, surface treatment, and image density only.
- Image 2: character identity anchor when provided. Preserve face, hair, costume language, weapon silhouette, and body proportions.
- Image 3: environment or prop anchor when provided. Use architecture, material language, and motif vocabulary only.
Do not copy composition, pose, or exact objects from a style anchor unless explicitly requested.
```

## Negative Block

```text
Avoid photorealistic skin, glossy CGI, plastic armor, cyberpunk neon, sci-fi panels, modern streetwear, generic anime school uniform, Japanese samurai armor, Chinese xianxia robe exaggeration, Western medieval plate armor, excessive bloom, lens flare, unreadable particles, random magic circles, over-detailed noisy background, distorted hands, extra fingers, unreadable weapon shapes, strong rim light, backlight halo, hard edge glow.
```

## Output Discipline Block

```text
Prioritize production usability: clear silhouette, readable costume layers, consistent lighting direction, simple large shapes before small ornaments, enough negative space for crop and UI use, no important detail at the image edge.
```
